# Forge Events Extension

## Purpose

Event-driven architecture for Forge apps: a publish/subscribe event bus, an append-only event
store with snapshots for event sourcing, and pluggable brokers (in-memory, core NATS, Redis
Pub/Sub, and Redis Streams with consumer groups and a dead-letter stream).

Module: github.com/xraph/forge/extensions/events (package `events`).

Subpackages:
- `core`: Event, EventBus, MessageBroker, DurableMessageBroker, EventStore, handlers, retry policy.
- `brokers`: NewMemoryBroker, NewNATSBroker, NewRedisBroker (Pub/Sub, or Streams with `enable_streams`).
- `stores`: NewMemoryEventStore, plus PostgreSQL and MongoDB stores (incomplete, see below).
- `schema`: SchemaRegistry and EventSchemaValidator. The bus never calls them for you.

## Constructors and options

```go
func NewExtension() forge.Extension                                              // DefaultConfig()
func NewExtensionWithConfig(config Config, options ...EventServiceOption) forge.Extension
func DefaultConfig() Config

type EventServiceOption func(*EventService)
func WithEventStore(store core.EventStore) EventServiceOption                    // borrowed: never closed
func WithEventStoreFactory(factory EventStoreFactory) EventServiceOption        // owned: built on each start
type EventStoreFactory func(context.Context, StoreConfig) (core.EventStore, error)

func NewEventService(config Config, logger forge.Logger, metrics forge.Metrics, options ...EventServiceOption) *EventService
func NewEventBus(config EventBusOptions) (core.EventBus, error)
```

There are no `WithXxx` config options; build a `Config` and use NewExtensionWithConfig.

## What the container holds

| Type | Alias | Helper |
| --- | --- | --- |
| `*events.EventService` | `events` (ServiceKey) | `GetEventService(c)` / `MustGetEventService(c)` |
| `core.EventBus` | `eventBus` (EventBusKey) | `GetEventBus(c)` / `MustGetEventBus(c)` |
| `core.EventStore` | `eventStore` (EventStoreKey) | `GetEventStore(c)` / `MustGetEventStore(c)` |
| `*core.HandlerRegistry` | `eventHandlerRegistry` (HandlerRegistryKey) | `GetHandlerRegistry(c)` / `MustGetHandlerRegistry(c)` |

`GetEventServiceFromApp(app)` and `MustGetEventServiceFromApp(app)` skip the Container() call.
The extension's Start opens the store, connects every enabled broker and starts the bus, so an
unreachable broker stops the app from starting.

## Key types (core)

```go
type Event struct {
    ID, Type, AggregateID string; Data any; Metadata map[string]any
    Timestamp time.Time; Version int; Source, CorrelationID, CausationID string
}
func NewEvent(eventType, aggregateID string, data any) *Event   // UUID, UTC time, version 1
// chainable: WithVersion, WithSource, WithCorrelationID, WithCausationID, WithMetadata(key, value)

type EventBus interface {
    Publish(ctx context.Context, event *Event) error            // saves to store, then sends
    PublishTo(ctx context.Context, brokerName string, event *Event) error  // no save
    Subscribe(eventType string, handler EventHandler) error     // on every registered broker
    Unsubscribe(eventType string, handlerName string) error
    RegisterBroker(name string, broker MessageBroker) error     // only while the bus is stopped
    UnregisterBroker(name string) error
    GetBroker(name string) (MessageBroker, error)
    GetBrokers() map[string]MessageBroker
    SetDefaultBroker(name string) error
    GetStats() map[string]any
    Start(ctx context.Context) error
    Stop(ctx context.Context) error
    HealthCheck(ctx context.Context) error
}

type EventHandler interface {
    Handle(ctx context.Context, event *Event) error
    CanHandle(event *Event) bool
    Name() string
}

type MessageBroker interface { Connect, Publish(ctx, topic string, event Event), Subscribe, Unsubscribe, Close, HealthCheck, GetStats }
type DurableMessageBroker interface { MessageBroker; DurableCapabilities() (DurableBrokerCapabilities, error); SubscribeDurable(ctx, topic string, handler EventHandler) error }
func RequireDurableBroker(broker MessageBroker) (DurableMessageBroker, error)  // ErrDurableDeliveryUnavailable otherwise
```

EventStore methods: SaveEvent, SaveEvents, GetEvent, GetEvents(ctx, EventCriteria),
GetEventsByAggregate(ctx, aggregateID, fromVersion), GetEventsByType(ctx, type, limit, offset),
GetEventsSince, GetEventsInRange, DeleteEvent, DeleteEventsByAggregate (soft deletes),
GetLastEvent, GetEventCount, GetEventCountByType, CreateSnapshot, GetSnapshot, DeleteSnapshot,
Close, HealthCheck.

## Handlers (re-exported from core in exports.go)

- `NewTypedEventHandler(name string, eventTypes []string, handler EventHandlerFunc) *TypedEventHandler`
  with `.WithMiddleware(...)`, `.WithRetryPolicy(p)`, `.WithMetrics(m)`, `.WithLogger(l)`.
- `NewDomainEventHandler(name, aggregateType string, eventTypes []string, handler EventHandlerFunc)`:
  only accepts events whose `aggregate_type` metadata matches.
- `NewReflectionEventHandler(name string, target any)`: calls `Handle<Type>(ctx, event)` on target,
  so it only fits event types that are valid Go identifiers.
- `core.EventHandlerFunc(fn)`: a bare function, subscribed anonymously. You can't unsubscribe it
  by name, and Redis Streams rejects it.
- `NewRetryPolicy(maxRetries int, initialDelay time.Duration) *RetryPolicy`: doubles the delay up
  to 5 minutes; `.WithMaxDelay`, `.WithBackoffFactor`, `.WithRetryableErrors`, `.WithShouldRetryFunc`.
- Middleware: `LoggingMiddleware(l)`, `MetricsMiddleware(m)`, `ValidationMiddleware()`.
- Store helpers: `NewEventCriteria()`, `NewSnapshot(aggregateID, snapshotType string, data any, version int)`.

## Usage

```go
bus, err := events.GetEventBus(app.Container())
h := events.NewTypedEventHandler("welcome-email", []string{"user.created"},
    func(ctx context.Context, e *core.Event) error { return nil })
err = bus.Subscribe("user.created", h)

err = bus.Publish(ctx, core.NewEvent("user.created", "user-1", payload).WithSource("accounts-api"))
```

Subscribe from a `forge.PhaseAfterStart` hook so the bus is running.

## Config

Read from `extensions.events` only (no top-level fallback), bound over the config you passed.

```yaml
extensions:
  events:
    bus:
      default_broker: memory   # empty = publish to every broker
      enable_metrics: true
    store:
      type: memory             # anything else needs WithEventStore or WithEventStoreFactory
      database: ""
      table: events
    brokers:
      - name: memory
        type: memory           # memory, nats, redis
        enabled: true
        config: {}
```

Validation: at least one enabled broker, unique names, a known type, and default_broker must be
an enabled broker. If you replace the broker list, set `bus.default_broker` too.

Broker `config` keys:
- nats: url (default nats://localhost:4222), name, username, password, token, max_reconnects,
  enable_compression. Core NATS only, no JetStream.
- redis: address or addresses (default localhost:6379), username, password, database, pool_size,
  master_name (Sentinel). Several addresses without master_name use a cluster client.
- redis with `enable_streams: true`: also consumer_group, consumer_name, stream_max_len,
  stream_max_deliveries (5), stream_claim_idle, stream_poll_interval, stream_lease_duration,
  stream_ordering. Streams mode refuses Redis Cluster.

## Delivery

- memory, NATS, Redis Pub/Sub: at most once. Each matching handler runs in its own goroutine
  (30s timeout on memory). A handler error is logged and the event is not redelivered, so put a
  RetryPolicy on the handler.
- Redis Streams: at least once. Returning nil acks; an error leaves the message pending until
  stream_claim_idle, and after stream_max_deliveries it moves to `<topic>:forge:dead-letter`.
  Handler names build the consumer group, so keep them stable.
- Publish fails if any destination fails, and a retry can deliver again to brokers that succeeded.

## Not implemented yet

- `bus.max_retries`, `bus.retry_delay`, `bus.processing_timeout`, `bus.buffer_size`,
  `bus.worker_count`, `bus.enable_tracing`, `brokers[].priority` and the whole `metrics` section
  exist on the config structs but the bus ignores them.
- `stores.NewPostgresEventStore` and `stores.NewMongoEventStore` don't implement the full
  `core.EventStore` interface, so you can't pass them to the service. The only built-in store
  is in memory and is lost on restart.
- No Kafka or NATS JetStream broker. Implement `core.MessageBroker` and `RegisterBroker` it while
  the bus is stopped.

## Testing

Redis integration tests in `brokers` skip unless `FORGE_EVENTS_REDIS_TEST_ADDR` is set.
