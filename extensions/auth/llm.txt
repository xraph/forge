# Forge Auth Extension

## Purpose

Authentication for Forge HTTP routes. Ready-made providers for API keys, Bearer tokens (JWTs),
HTTP Basic, OAuth 2.0, OpenID Connect and LDAP / Active Directory; a registry that chains them;
and route middleware that checks scopes, roles and permissions before the handler runs. You
write the validator that knows your users. The registry reads the credential, tries providers,
and answers 401 or 403.

Module: github.com/xraph/forge/extensions/auth (package `auth`), with providers in
github.com/xraph/forge/extensions/auth/providers.

## Use the registry directly (today)

```go
registry := auth.NewRegistry(app.Container(), app.Logger())
_ = registry.Register(providers.NewAPIKeyProvider("api-key",
    providers.WithAPIKeyValidator(func(ctx context.Context, key string) (*auth.AuthContext, error) {
        if key != "alice-key" {
            return nil, auth.ErrInvalidCredentials
        }
        return &auth.AuthContext{Subject: "alice", Roles: []string{"admin"}}, nil
    }),
))

adminsOnly := registry.MiddlewareWithRequirement(auth.Requirement{
    Providers: []string{"api-key"},
    Roles:     []string{"admin"},
})
_ = app.Router().DELETE("/cache", handler,
    forge.WithMiddleware(adminsOnly),
    forge.WithAuth("api-key"), forge.WithAnyRole("admin"))   // metadata for OpenAPI only
```

In the handler: `authCtx, ok := auth.GetAuthContext(ctx)` (ctx is forge.Context).

## Key types

```go
type AuthProvider interface {
    Name() string
    Type() SecuritySchemeType
    Authenticate(ctx context.Context, r *http.Request) (*AuthContext, error)
    OpenAPIScheme() SecurityScheme
    Middleware() forge.Middleware
}

type AuthContext struct {
    Subject string; Claims map[string]any; Scopes, Roles, Permissions []string
    Metadata map[string]any; Data any; ProviderName string
}
// methods: HasScope, HasScopes, HasRole, HasAnyRole, HasPermission, HasAllPermissions,
//          GetClaim(key) (any, bool), GetClaimString(key) (string, bool)

type Registry interface {
    Register(provider AuthProvider) error
    Unregister(name string) error
    Get(name string) (AuthProvider, error)
    Has(name string) bool
    List() []string
    Middleware(providerNames ...string) forge.Middleware          // first success wins (OR)
    MiddlewareAnd(providerNames ...string) forge.Middleware       // all must succeed
    MiddlewareWithScopes(providerName string, scopes ...string) forge.Middleware
    MiddlewareWithRequirement(req Requirement) forge.Middleware   // authenticate, then authorize
    OpenAPISchemes() map[string]SecurityScheme
    SetAuthorizer(a Authorizer)                                   // nil is ignored
    Authorizer() Authorizer
}
func NewRegistry(container forge.Container, logger forge.Logger) Registry

type Requirement struct {
    Providers   []string
    Scopes      []string   // all required
    Roles       []string   // any one is enough
    Permissions []string   // all required
    Mode        string     // "or" (default) or "and", applies to Providers
}

type Authorizer interface {
    Name() string
    Authorize(ctx context.Context, authCtx *AuthContext, req Requirement) error  // nil allows
}
func NewDefaultAuthorizer() Authorizer   // plain set membership, no hierarchy, no wildcards
```

SecuritySchemeType constants: SecurityTypeAPIKey, SecurityTypeHTTP, SecurityTypeOAuth2,
SecurityTypeOpenIDConnect, SecurityTypeMutualTLS. SecurityScheme, OAuthFlows and OAuthFlow are
aliases of the router's shared types. `ProviderFunc func(ctx, *http.Request) (*AuthContext, error)`.

## Providers (package providers)

| Constructor | Reads | Options |
| --- | --- | --- |
| NewAPIKeyProvider(name, ...APIKeyOption) auth.AuthProvider | header (X-API-Key), then query, then cookie | WithAPIKeyHeader, WithAPIKeyQuery, WithAPIKeyCookie, WithAPIKeyValidator, WithAPIKeyDescription, WithAPIKeyContainer |
| NewBearerTokenProvider(name, ...BearerTokenOption) | Authorization: Bearer | WithBearerFormat, WithBearerValidator, WithBearerDescription, WithBearerContainer |
| NewBasicAuthProvider(name, ...BasicAuthOption) | Authorization: Basic | WithBasicAuthValidator, WithBasicAuthDescription, WithBasicAuthContainer |
| NewOAuth2Provider(name, flows *auth.OAuthFlows, ...OAuth2Option) | Bearer token | WithOAuth2Validator, WithOAuth2Description, WithOAuth2Container |
| NewOIDCProvider(name, openIdConnectUrl string, ...OIDCOption) | Bearer token | WithOIDCValidator, WithOIDCDescription, WithOIDCContainer |
| NewLDAPProvider(config LDAPConfig, logger forge.Logger) (*LDAPProvider, error) | HTTP Basic, checked against the directory | DefaultLDAPConfig() |

Validator types: APIKeyValidator, BearerTokenValidator, OAuth2TokenValidator, OIDCTokenValidator
(all `func(ctx, token string) (*auth.AuthContext, error)`), BasicAuthValidator
`func(ctx, username, password string) (*auth.AuthContext, error)`. A provider without a
validator returns ErrInvalidConfiguration on every request.

Bearer, OAuth2 and OIDC do not verify tokens. Check signature, expiry and audience in your
validator; the flows and discovery URL only feed the OpenAPI scheme.

LDAP (registered as "ldap"): DefaultLDAPConfig sets port 389, use_tls true (StartTLS, TLS 1.2+,
hostname verified), pool_size 10, cache 5m, search_filter "(uid=%s)", group_filter
"(member=%s)", attributes uid/mail/displayName/memberOf. Mapped groups (RoleMapping, group DN to
name; empty passes every DN through) land in `Scopes`, not `Roles`. Setting insecure_skip_verify
true makes NewLDAPProvider return an error.

## Context helpers

GetAuthContext(ctx forge.Context), MustGetAuthContext, FromContext(ctx context.Context),
MustFromContext, WithContext(ctx, authCtx), GetAuthContextFromStdContext.

The registry middleware stores the auth context with `ctx.Set`, not in the request context, so
`FromContext(ctx.Context())` only finds it if you copy it there with WithContext.
MiddlewareWithRequirement also sets `auth.subject.roles` and `auth.subject.scopes`.

Frame credentials (for WebSocket or SSE control frames): ParseExplicitFrameCredential(presentation)
(scheme, token, err) accepts a bare token, "Bearer <t>" or "DPoP <t>"; WithExplicitFrameCredential
and MatchesExplicitFrameCredential mark and check it. The mark grants no identity.

## Responses and errors

Failed sign-in: plain-text 401. Failed authorization: 403 with the authorizer's error text.
Sentinels: ErrProviderNotFound, ErrProviderExists, ErrInvalidConfiguration,
ErrMissingCredentials, ErrInvalidCredentials, ErrInsufficientScopes, ErrAuthenticationFailed,
ErrAuthorizationFailed, ErrTokenExpired, ErrTokenInvalid.

## Route metadata

forge.WithAuth, WithRequiredAuth, WithAuthAnd, WithAnyRole, WithAllPermissions and the
WithGroup... versions only record metadata for the OpenAPI and client generators. Nothing is
enforced until registry middleware is on the route.

## The extension

```go
func NewExtension(opts ...ConfigOption) forge.Extension
func NewExtensionWithConfig(config Config) forge.Extension
WithEnabled(bool), WithAuthorizer(Authorizer), WithProviders(...ProviderConfig),
WithDefaultProvider(string), WithRequireConfig(bool), WithConfig(Config)
```

Config comes from `extensions.auth` (falling back to `auth`) and from options. Options win over
the file, the file over defaults. Keys are snake_case: enabled, default_provider, providers
(name, type, enabled, description, config). Authorizer is code only. When enabled, Register adds a `Registry` constructor under the
names `auth:registry` (RegistryKey) and `auth.Registry` (RegistryKeyLegacy). Helpers:
GetRegistry(c), MustGetRegistry(c), GetRegistryFromApp(app), MustGetRegistryFromApp(app).

## Not implemented yet

- Resolving the registry from the container fails: the constructor asks the container for a
  `forge.Container`, which nothing provides ("no provider for type di.Container"). Build it with
  `auth.NewRegistry(app.Container(), app.Logger())` and keep the reference. Because of this the
  OpenAPI generator's lookup of `auth:registry` finds nothing, so security scheme definitions
  aren't added to components (operations still get `security` requirements).
- `providers` and `default_provider` (from options or YAML) are stored on Config but Register
  doesn't read them.
- `examples/auth_example` resolves the registry from the container and won't run unmodified.
