## Overview

`github.com/xraph/forge/extensions/dashboard` serves your dashboard's data. It collects health, metrics, services and request traces from the running app, and exposes them, along with anything your own extensions contribute, through one RPC endpoint: the dashboard contract at `{BasePath}/api/dashboard/v1`.

It serves no web pages. The UI is a separate React app built from the `@forge-go/dashboard-*` packages, and you build and serve it yourself. `forge dashboard new` scaffolds one for you, either a standalone Vite app or a mount inside an existing Next.js app.

<Callout type="info">
Extensions contribute to the dashboard in two halves: a contract contributor in Go that registers intents, and a React plugin that renders them. See [Features](/docs/extensions/dashboard/features#contributing-from-an-extension).
</Callout>

## Quick Start

```go
package main

import (
    "log"
    "time"

    "github.com/xraph/forge"
    "github.com/xraph/forge/extensions/dashboard"
)

func main() {
    app := forge.New(
        forge.WithAppName("my-app"),
        forge.WithAppVersion("1.0.0"),
    )

    if err := app.RegisterExtension(dashboard.NewExtension(
        dashboard.WithBasePath("/dashboard"),
        dashboard.WithRefreshInterval(30 * time.Second),
        dashboard.WithExport(true),
    )); err != nil {
        log.Fatalf("failed to register dashboard: %v", err)
    }

    // The contract is now at http://localhost:8080/dashboard/api/dashboard/v1
    if err := app.Run(); err != nil {
        log.Fatalf("application error: %v", err)
    }
}
```

Then scaffold the UI and point it at that endpoint:

```sh
forge dashboard new my-dashboard
```

## What It Registers

| Service | DI Key | Type |
|---|---|---|
| Dashboard extension | `dashboard` | `*Extension` |

Routes are mounted on the Forge router during `Start()`, under the configured base path (default `/dashboard`).

## HTTP Endpoints

All paths are relative to the base path.

### Contract

| Method | Path | Description |
|---|---|---|
| POST | `/api/dashboard/v1` | The contract envelope: queries and commands |
| GET | `/api/dashboard/v1/capabilities` | Supported envelope versions and every registered contributor, with its status |
| GET | `/api/dashboard/v1/principal` | The signed-in user, or 401 with the login path when auth is on |
| GET | `/api/dashboard/v1/csrf` | A CSRF token for commands (when CSRF and contract security are on) |
| GET | `/api/dashboard/v1/stream` | Server-sent events carrying subscription updates |
| POST | `/api/dashboard/v1/stream/control` | Subscribe and unsubscribe on an open stream |

The envelope is capped at 1 MiB by default. A bigger body gets a 413 before it's decoded. You can change the cap with `WithContractMaxBodyBytes`.

### Export

| Method | Path | Description |
|---|---|---|
| GET | `/export/json` | Full JSON snapshot |
| GET | `/export/csv` | Metrics as CSV |
| GET | `/export/prometheus` | Prometheus text format |

Export routes register only when `EnableExport` is true, which is the default.

## Programmatic Access

You can pull the extension out of the DI container and read its data directly:

```go
ext, _ := forge.InjectType[*dashboard.Extension](app.Container())

overview := ext.Collector().CollectOverview(ctx)
health := ext.Collector().CollectHealth(ctx)
history := ext.History().GetAll()
traces := ext.TraceStore()
```
