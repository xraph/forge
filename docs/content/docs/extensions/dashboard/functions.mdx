## Constructors

| Function | Signature | Description |
|---|---|---|
| `NewExtension` | `(opts ...ConfigOption) forge.Extension` | Create the dashboard extension with functional options |
| `DefaultConfig` | `() Config` | Returns the default configuration |

## Package Functions

| Function | Signature | Description |
|---|---|---|
| `TracingMiddleware` | `(store *collector.TraceStore, basePath string, captureRequestBody ...bool) forge.Middleware` | The middleware `Start()` installs, so you don't call it yourself. It starts no spans: your app's tracing already does. It stamps dashboard activity (requests under `basePath` keep the trace gate open) and captures allowlisted headers, plus a redacted body when `captureRequestBody` is true, for the span that tracing started |
| `AdaptIdempotencyStore` | `(s idempotency.Store) dispatcher.IdempotencyStore` | Wrap a `contract/idempotency` store for `dispatcher.WithIdempotencyStore`, the same way the extension wires its own dispatcher. A store that can claim keys comes back as a `dispatcher.IdempotencyClaimer` |

## Extension Methods

### Data

| Method | Returns | Description |
|---|---|---|
| `Collector()` | `*collector.DataCollector` | Overview, health, metrics and services, collected on `RefreshInterval` |
| `History()` | `*collector.DataHistory` | Time-series history of collected data |
| `TraceStore()` | `*collector.TraceStore` | Recorded request traces |
| `BasePath()` | `string` | The prefix every dashboard route is mounted under |

### Remote Contributors

| Method | Signature | Description |
|---|---|---|
| `RegisterRemoteContractContributor` | `(ctx context.Context, baseURL, apiKey string) error` | Fetch a remote service's contract manifest and forward that contributor's envelopes to it |
| `UnregisterRemoteContractContributor` | `(name string)` | Remove a remote contributor. Safe for unknown names |
| `SetDiscoveryService` | `(svc discovery.DiscoveryService)` | Find remote contributors through service discovery. Needs `WithDiscovery(true)` |

### Auth

| Method | Signature | Description |
|---|---|---|
| `SetAuthChecker` | `(checker dashauth.AuthChecker)` | Set the checker run on every contract request |
| `AuthChecker` | `() dashauth.AuthChecker` | The configured checker, or `nil` |
| `EnableAuth` | `()` | Turn auth on. Auth extensions call this from `RegisterDashboardAuth` |
| `SetRequiredRoles` | `(roles []string)` | Make `/principal` answer 403 for users without one of these roles. The envelope endpoint doesn't check it |
| `SetTenantResolver` | `(resolver dashauth.TenantResolver)` | Resolve a tenant for every request, readable with `dashauth.TenantFromContext` |
| `TenantResolver` | `() dashauth.TenantResolver` | The configured resolver, or `nil` |
| `CSRFManager` | `() *security.CSRFManager` | The CSRF manager, or `nil` when CSRF is off |

### Lifecycle

| Method | Signature | Description |
|---|---|---|
| `Register` | `(app forge.App) error` | Load and validate config, build the collector, trace store and contract dispatcher, register the core intents |
| `Start` | `(ctx context.Context) error` | Discover contributors and auth providers, mount routes, start collection |
| `Stop` | `(ctx context.Context) error` | Stop the collector and close the trace store |
| `Health` | `(ctx context.Context) error` | `nil` once the collector exists, otherwise `ErrCollectorNotInitialized` |

## Interfaces an Extension Can Implement

The dashboard looks for these on every registered extension during `Start()`.

| Interface | Method | Purpose |
|---|---|---|
| `ContractContributorAware` | `RegisterContractContributor(disp, reg, wreg) error` | Register your intents and their handlers |
| `DashboardStatusAware` | `DashboardStatus() DashboardStatus` | Report your version and whether you're configured |
| `DashboardAuthAware` | `RegisterDashboardAuth(ext *Extension)` | Wire an `AuthChecker`, roles and tenant resolution |

## Error Sentinels

| Error | Description |
|---|---|
| `ErrCollectorNotInitialized` | The data collector hasn't been built yet |
