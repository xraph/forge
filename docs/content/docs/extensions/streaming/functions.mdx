## Extension entry points

| Function | Description |
|---|---|
| `NewExtension(opts ...ConfigOption) *Extension` | Create the extension from `DefaultConfig()` plus your options. It returns the concrete type so you can reach the methods below |
| `NewExtensionWithConfig(config Config) *Extension` | Same as `NewExtension(WithConfig(config))` |
| `DefaultConfig() Config` | The defaults listed on the [configuration page](/docs/extensions/streaming/configuration) |
| `ManagerKey` | `"streaming"`, the alias the manager is registered under |

## `*Extension` methods

Call these after the app has registered its extensions, for example from a `forge.OnStarted` hook.

| Method | Description |
|---|---|
| `RegisterRoutes(router forge.Router, wsPath, ssePath string) error` | Mount the WebSocket route, the SSE route, and `POST {ssePath}/subscribe` and `/unsubscribe` |
| `Manager() Manager` | The manager the extension built |
| `RegisterHook(hook StreamingHook)`, `UnregisterHook(name string)` | Add or remove a hook |
| `RegisterCodec(codec Codec)` | Add a codec for a content type |
| `Hooks() *HookRegistry`, `Codecs() *CodecRegistry` | The registries themselves |
| `AsyncAPISpec() *forge.AsyncAPISpec` | An AsyncAPI description of the WebSocket protocol |
| `RegisterContractContributor(...)` | Called by the dashboard extension to serve the streaming contract pages |

## DI helpers

| Function | Description |
|---|---|
| `GetManager(c forge.Container) (Manager, error)` | Resolve the manager |
| `MustGetManager(c forge.Container) Manager` | Same, panics on error |
| `GetManagerFromApp(app forge.App) (Manager, error)` | Resolve from an app |
| `MustGetManagerFromApp(app forge.App) Manager` | Same, panics on error |

## Constructors and helpers

| Function | Description |
|---|---|
| `NewLocalRoom(opts RoomOptions) *local.LocalRoom` | A `Room` to pass to `Manager.CreateRoom` |
| `NewConnection(conn forge.Connection, opts ...ConnOption) Connection` | Wrap a Forge connection with user, session, room and channel tracking |
| `NewConnectionWithTransport(conn forge.Connection, transport string, opts ...ConnOption) Connection` | Same, with a transport name |
| `NewSSEConnection(stream forge.Stream, remoteAddr, localAddr string) forge.Connection` | Adapt an SSE stream to a `forge.Connection` |
| `NewEventMessage(event string, data any) *Message` | A `message` frame with a domain event name |
| `NewLifecycleMessage(kind, lifecycle string) *Message` | A transport frame with the lifecycle name in `Metadata` |
| `TransportKinds() []string`, `IsTransportKind(kind string) bool` | The reserved `type` values |
| `NewHookRegistry() *HookRegistry`, `NewCodecRegistry() *CodecRegistry` | Standalone registries |
| `NewInMemorySessionStore() SessionStore` | The store session resumption uses |

## `Manager`

### Connections

| Method | Description |
|---|---|
| `Register(conn Connection) error` | Add a connection; enforces the connection limits |
| `Unregister(connID string) error` | Remove it |
| `GetConnection(connID string) (Connection, error)` | One connection |
| `GetUserConnections(userID string) []Connection` | Every connection of a user |
| `GetAllConnections() []Connection`, `ConnectionCount() int` | All of them |
| `GetConnectionInfo(connID string) (*ConnectionInfo, error)` | A snapshot of one |
| `KickConnection(ctx, connID, reason string) error` | Disconnect one |
| `GetIdleConnections(idleFor time.Duration) []Connection` | Connections idle that long |
| `CleanupIdleConnections(ctx, idleFor time.Duration) (int, error)` | Close them |
| `ProcessInbound(ctx, message *Message, sender Connection) (*Message, error)` | The size, rate, authorization and validation gate for client messages |

### Rooms

| Method | Description |
|---|---|
| `CreateRoom(ctx, room Room) error` | Create a room, usually from `NewLocalRoom` |
| `GetRoom(ctx, roomID) (Room, error)`, `ListRooms(ctx) ([]Room, error)` | Look rooms up |
| `DeleteRoom(ctx, roomID) error` | Delete one |
| `JoinRoom(ctx, connID, roomID string) error` | Join a connection to a room. Needs a user ID |
| `LeaveRoom(ctx, connID, roomID string) error` | Leave |
| `BulkJoinRoom(ctx, connIDs []string, roomID string) error` | Join several connections |
| `GetRoomMembers(ctx, roomID) ([]Member, error)` | Members |
| `UpdateRoom`, `SearchRooms`, `GetPublicRooms`, `GetUserRoomCount` | More lookups and updates |
| `ArchiveRoom`, `RestoreRoom`, `TransferRoomOwnership` | Room lifecycle |
| `MuteUser`, `UnmuteUser`, `BanUser`, `UnbanUser`, `GetModerationLog` | Moderation, per room |
| `CreateDirectMessage(ctx, fromUserID, toUserID) (string, error)`, `GetDirectMessages`, `IsDirectMessage` | Direct message rooms |

### Channels

| Method | Description |
|---|---|
| `CreateChannel(ctx, channel Channel) error` | Create a channel. See the note on the [features page](/docs/extensions/streaming/features#channels) |
| `GetChannel`, `ListChannels`, `DeleteChannel`, `UpdateChannel` | Manage channels |
| `Subscribe(ctx, connID, channelID string, filters map[string]any) error` | Subscribe a connection |
| `Unsubscribe(ctx, connID, channelID string) error` | Unsubscribe |
| `GetChannelSubscribers`, `GetUserChannels` | Lookups |

### Broadcasting

Every one takes a `*Message`.

| Method | Description |
|---|---|
| `Broadcast(ctx, message) error` | Every connection on the node, and other nodes through the coordinator |
| `BroadcastToRoom(ctx, roomID, message) error` | Room members |
| `BroadcastToChannel(ctx, channelID, message) error` | Channel subscribers |
| `SendToUser(ctx, userID, message) error` | Every connection of one user |
| `SendToConnection(ctx, connID, message) error` | One connection |
| `BroadcastToUsers`, `BroadcastToRooms`, `BroadcastExcept` | Bulk variants |

### Presence and typing

| Method | Description |
|---|---|
| `SetPresence(ctx, userID, status string) error` | `StatusOnline`, `StatusAway`, `StatusBusy` or `StatusOffline` |
| `GetPresence(ctx, userID) (*UserPresence, error)` | One user |
| `GetOnlineUsers(ctx, roomID string) ([]string, error)` | Online users, limited to a room's members when `roomID` isn't empty |
| `GetPresenceForUsers`, `GetPresenceInRooms`, `GetOnlineCount`, `SetCustomStatus`, `TrackActivity` | More presence |
| `StartTyping(ctx, userID, roomID string) error`, `StopTyping` | User first, then room |
| `GetTypingUsers(ctx, roomID) ([]string, error)`, `IsTyping`, `ClearTyping`, `GetTypingUsersInChannels` | Typing lookups |

### History and replay

| Method | Description |
|---|---|
| `SaveMessage(ctx, message *Message) error` | Store a message and assign its room sequence |
| `GetHistory(ctx, roomID string, query HistoryQuery) ([]*Message, error)` | Room history |
| `GetThreadHistory`, `GetUserMessages`, `SearchMessages` | Narrower queries |
| `EditMessage`, `DeleteMessage` | Change history |
| `AddReaction`, `RemoveReaction`, `GetReactions` | Reactions |
| `Replay(ctx, connID, cursorToken string) (int, error)` | Send a connection what it missed since an SSE cursor |
| `ResumeSession(ctx, connID, sessionID string) (bool, error)` | Restore a disconnected session's rooms and channels |

### Limits, stats and lifecycle

| Method | Description |
|---|---|
| `CheckRateLimit(ctx, userID, action string) (bool, error)`, `GetRateLimitStatus` | Rate limiter state |
| `GetStats(ctx) (*ManagerStats, error)` | Node-wide counts |
| `GetRoomStats`, `GetUserStats`, `GetActiveRooms` | Narrower stats |
| `Start`, `Drain`, `Stop`, `Health` | Lifecycle, driven by the extension |

## Key types

| Type | What it is |
|---|---|
| `Message` | The wire envelope: `ID`, `Type`, `Event`, `RoomID`, `ChannelID`, `UserID`, `Data`, `Metadata`, `Timestamp`, `ThreadID`, `Sequence`, `ContentType`, `RawData` |
| `Connection` | A connection with `GetUserID`/`SetUserID`, `GetSessionID`/`SetSessionID`, metadata, joined rooms and subscriptions |
| `Room`, `Member`, `Channel` | Store-backed interfaces |
| `RoomOptions` | `ID`, `Name`, `Description`, `Owner`, `Private`, `MaxMembers`, `Metadata` |
| `HistoryQuery` | `Limit`, `Before`, `After`, `ThreadID`, `UserID`, `SearchTerm` |
| `UserPresence` | `UserID`, `Status`, `LastSeen`, `Connections`, `CustomStatus`, `Metadata` |
| `StreamingHook` and `ConnectionHook`, `MessageHook`, `RawMessageHook`, `RoomHook`, `PresenceHook`, `ErrorHook` | Hook interfaces |
| `Codec` | `ContentType()`, `Encode(*Message)`, `Decode([]byte, *Message)` |

Message kinds are `MessageTypeMessage`, `MessageTypeJoin`, `MessageTypeLeave`, `MessageTypeTyping`, `MessageTypePresence`, `MessageTypeSystem` and `MessageTypeError`. Content types are `ContentTypeJSON`, `ContentTypeBinary`, `ContentTypeText`, `ContentTypeMsgPack` and `ContentTypeProtobuf`.
