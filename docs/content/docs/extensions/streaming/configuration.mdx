## Where config comes from

The extension reads `extensions.streaming` from your config file, falling back to a top-level `streaming` key. Defaults come first, the file overrides them, and options you set in code override the file. A field you leave out of the file keeps its default.

One catch: a field you set in code to exactly its default value looks untouched, so the file wins for that field.

Forge reads `config.yaml` only when `EnableConfigAutoDiscovery` is on. `forge.DefaultAppConfig()` turns it on; a bare `forge.AppConfig{}` literal leaves it off.

## YAML example

The keys are the snake_case names from the struct tags. Durations take Go duration strings.

```yaml title="config.yaml"
extensions:
  streaming:
    backend: "redis"                 # "local" (default), "redis" or "nats" (not implemented)
    backend_urls: ["localhost:6379"]   # host:port, not a redis:// URL
    enable_distributed: true         # needs redis; WithRedisBackend sets it for you
    node_id: "api-1"                 # generated when empty in distributed mode

    # Features
    enable_rooms: true
    enable_channels: true
    enable_presence: true
    enable_typing_indicators: true
    enable_message_history: true

    # Limits
    max_connections_per_user: 5
    max_anonymous_connections: 1000
    max_total_connections: 20000     # 0 means unbounded
    max_rooms_per_user: 50
    max_channels_per_user: 100
    max_message_size: 65536          # bytes
    max_messages_per_second: 100

    # WebSocket keepalive
    ping_interval: "30s"
    pong_timeout: "10s"

    # Presence and typing
    presence_timeout: "5m"
    presence_cleanup: "1m"
    typing_timeout: "3s"
    typing_cleanup: "1s"
    max_typing_users_per_room: 10

    # Multi-node
    enable_load_balancer: true
    load_balancer_strategy: "consistent_hash"
    enable_session_resumption: true
    session_resumption_ttl: "2m"

    drain_timeout: "15s"
```

## Programmatic configuration

```go
ext := streaming.NewExtension(
	streaming.WithRedisBackend("localhost:6379"),
	streaming.WithNodeID("api-1"),
	streaming.WithFeatures(true, true, true, true, true),
	streaming.WithConnectionLimits(10, 100, 200),
	streaming.WithMessageLimits(32*1024, 50),
	streaming.WithPresenceTimeout(10*time.Minute),
	streaming.WithSessionResumption(2*time.Minute),
)
```

Settings with no option of their own go through `WithConfig`:

```go
cfg := streaming.DefaultConfig()
cfg.MaxTotalConnections = 20000
cfg.DrainTimeout = 30 * time.Second

ext := streaming.NewExtension(streaming.WithConfig(cfg))
```

## Option helpers

| Option | Sets |
|---|---|
| `WithLocalBackend()` | `backend: local`, distributed off |
| `WithRedisBackend(url)` | `backend: redis`, one URL, distributed on |
| `WithNATSBackend(urls...)` | `backend: nats`, distributed on. Registration then fails, NATS isn't implemented |
| `WithBackend(name)`, `WithBackendURLs(urls...)` | The same, field by field. They don't touch `EnableDistributed` |
| `WithAuthentication(user, pass)` | Backend credentials |
| `WithTLS(cert, key, ca)` | TLS for the backend connection, and turns `TLSEnabled` on |
| `WithFeatures(rooms, channels, presence, typing, history)` | Feature switches, all on by default |
| `WithConnectionLimits(perUser, roomsPerUser, channelsPerUser)` | `5`, `50`, `100` |
| `WithMessageLimits(maxSize, maxPerSecond)` | `65536` bytes, `100` a second |
| `WithTimeouts(ping, pong, write)` | `30s`, `10s`, `10s`. Write isn't read |
| `WithBufferSizes(read, write)` | `4096`, `4096`. Neither is read |
| `WithMessageRetention(d)` | `720h`. Not read |
| `WithPresenceTimeout(d)`, `WithTypingTimeout(d)` | `5m`, `3s` |
| `WithNodeID(id)` | Node ID for distributed mode |
| `WithLoadBalancer(strategy)` | Turns the load balancer on. Empty keeps `round_robin` |
| `WithSessionResumption(ttl)` | Turns resumption on. Zero keeps the 30s TTL |
| `WithRequireConfig(require)` | Fail registration when no `streaming` config is found |
| `WithConfig(cfg)` | Replace the whole config |

`NewExtensionWithConfig(cfg)` is the same as `NewExtension(WithConfig(cfg))`.

## Validation

Registration fails when:

- `backend` is anything other than `local`, `redis`, `nats` or empty;
- `enable_distributed` is on with the `local` backend;
- `redis` or `nats` has no `backend_urls`;
- `max_connections_per_user` or `max_message_size` is below 1;
- `ping_interval` or `pong_timeout` is under a second;
- `tls_enabled` is on without a cert and key file.

## Fields that do nothing yet

<Callout type="warn">
These are stored, and a few of them show up on the dashboard, but nothing acts on them.
</Callout>

- `write_timeout`, `read_buffer_size`, `write_buffer_size`.
- `message_retention`, `message_cleanup`, `max_messages_per_room`: history is never trimmed.
- `heartbeat_interval`, `node_timeout`.
