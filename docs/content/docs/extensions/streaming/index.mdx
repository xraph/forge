## Overview

`github.com/xraph/forge/extensions/streaming` gives your app ready-made WebSocket and Server-Sent Events (SSE) endpoints and a `Manager` that handles rooms, pub/sub channels, presence, typing indicators, message history and gap-free replay after a reconnect. You can run it on one node with the local in-memory backend, or across several with Redis. Whatever a client sends goes through a size limit, a per-user rate limit and room authorization before anyone else sees it.

## What it registers

| Service | How you resolve it | Type |
|---|---|---|
| Streaming manager | `ext.Manager()`, `streaming.GetManager(container)` or `forge.Inject[streaming.Manager](container)`, alias `streaming` | `streaming.Manager` |

Routes aren't mounted for you. You call `RegisterRoutes(router, wsPath, ssePath)`, which adds the WebSocket route, the SSE route, and `POST {ssePath}/subscribe` and `{ssePath}/unsubscribe`.

## Quick start

```bash
go get github.com/xraph/forge@latest
go get github.com/xraph/forge/extensions/streaming@latest
```

```go title="main.go"
package main

import (
	"context"
	"log"
	"net/http"

	"github.com/xraph/forge"
	"github.com/xraph/forge/extensions/streaming"
)

func main() {
	stream := streaming.NewExtension(streaming.WithLocalBackend())

	app := forge.NewApp(forge.AppConfig{
		Name:        "live-updates",
		HTTPAddress: ":8080",
		Extensions:  []forge.Extension{stream},
	})

	// The extension builds its manager when the app registers it, so mount
	// the built-in handlers from a start hook: WebSocket on /ws, SSE on
	// /events, plus POST /events/subscribe and /events/unsubscribe.
	err := forge.OnStarted(app, "streaming-routes", func(_ context.Context, a forge.App) error {
		return stream.RegisterRoutes(a.Router(), "/ws", "/events")
	})
	if err != nil {
		log.Fatal(err)
	}

	// Send a message to every open WebSocket and SSE connection.
	err = app.Router().POST("/announce", func(ctx forge.Context) error {
		msg := streaming.NewEventMessage("announcement", ctx.Query("text"))

		if err := stream.Manager().Broadcast(ctx.Context(), msg); err != nil {
			return err
		}

		return ctx.JSON(http.StatusAccepted, map[string]string{"status": "sent"})
	})
	if err != nil {
		log.Fatal(err)
	}

	if err := app.Run(); err != nil {
		log.Fatal(err)
	}
}
```

Run it, open an SSE stream in one terminal and send from another:

```bash
go mod tidy && go run .

curl -N http://localhost:8080/events
curl -X POST 'http://localhost:8080/announce?text=deploy+finished'
```

The stream prints a `connected` event with your connection and session IDs, then the announcement:

```text
event: connected
data: {"conn_id":"a5ef...","resumed":false,"session_id":"389f..."}

event: message
data: {"id":"","type":"message","event":"announcement","user_id":"","data":"deploy finished","timestamp":"..."}
```

A WebSocket client on `ws://localhost:8080/ws` gets the same JSON as a text frame.

<Callout type="warn">
Call `RegisterRoutes`, `RegisterHook` and `RegisterCodec` from a start hook like the one above, or anywhere after the app has registered its extensions. The extension creates its logger, hook registry and manager during registration, so calling them earlier panics with a nil pointer.
</Callout>

## Identity and authentication

Joining a room needs a user. The built-in handlers read the caller's ID from the `user_id` value on the Forge context. A connection without one is anonymous: it receives broadcasts, but `JoinRoom` refuses it and the SSE subscribe endpoints answer 404.

Values that route or group middleware stores with `ctx.Set` reach the WebSocket and SSE handlers, so you authenticate with ordinary middleware. Mount the routes on a group that has it:

```go
requireUser := func(next forge.Handler) forge.Handler {
	return func(ctx forge.Context) error {
		userID := ctx.Header("X-User-ID") // replace with your real auth check
		if userID == "" {
			return forge.Unauthorized("sign in first")
		}

		ctx.Set("user_id", userID)

		return next(ctx)
	}
}

err := forge.OnStarted(app, "streaming-routes", func(_ context.Context, a forge.App) error {
	rt := a.Router().Group("/rt", forge.WithGroupMiddleware(requireUser))

	return stream.RegisterRoutes(rt, "/ws", "/events")
})
```

The value has to be a `string`. Browsers can't set headers on a WebSocket or `EventSource` request, so in practice you'll read a cookie or a token from the query string.

## Rooms

Rooms must exist before anyone joins them, so you create them from your own code:

```go
err := stream.Manager().CreateRoom(ctx, streaming.NewLocalRoom(streaming.RoomOptions{
	ID:    "lobby",
	Name:  "Lobby",
	Owner: "system",
}))
```

The default room authorizer lets any user into a public room and only members into a private one. A client joins with `{"type": "join", "room_id": "lobby"}` over WebSocket, or `?rooms=lobby` on the SSE URL.

## Using the manager in your services

```go
type ChatService struct {
	streams streaming.Manager
}

func NewChatService(mgr streaming.Manager) *ChatService {
	return &ChatService{streams: mgr}
}

func (s *ChatService) Notify(ctx context.Context, roomID, text string) error {
	msg := streaming.NewEventMessage("chat.notice", text)
	msg.RoomID = roomID

	if err := s.streams.SaveMessage(ctx, msg); err != nil {
		return err
	}

	return s.streams.BroadcastToRoom(ctx, roomID, msg)
}
```

Register it with `forge.ProvideConstructor(app.Container(), NewChatService)`. Every broadcast method takes a `*streaming.Message`, not raw bytes.

## Status

- The NATS backend isn't implemented. `WithNATSBackend` passes validation, then registration fails with a backend error.
- Channels can't be created from outside the module yet. `CreateChannel` takes a `Channel`, and the options type the local constructor needs isn't exported, so subscribes fail with `ErrChannelNotFound`. Rooms work.
- `round_robin`, the default load balancer strategy, uses least connections.
- Several config fields, such as `message_retention` and the buffer sizes, are never read. The [configuration page](/docs/extensions/streaming/configuration#fields-that-do-nothing-yet) lists them.
