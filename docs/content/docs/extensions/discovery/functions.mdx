## Extension entry points

| Function | Description |
|---|---|
| `NewExtension(opts ...ConfigOption) forge.Extension` | The extension. Options apply over the defaults and the config file |
| `NewExtensionWithConfig(config Config) forge.Extension` | The extension with a complete config |
| `DefaultConfig() Config` | The defaults |

Every `With...` option is listed on the [Configuration](/docs/extensions/discovery/configuration#options) page.

## Resolving the service

The package has no `Get` or `MustGet` helpers. Use Forge's DI:

```go
svc, err := forge.Inject[*discovery.Service](app.Container())
```

The service is also registered under the names `discovery` and `discovery.Service`.

## Service: registration

| Method | Description |
|---|---|
| `Register(ctx, instance *ServiceInstance) error` | Register an instance with the backend. Set `Status` yourself |
| `Deregister(ctx, serviceID string) error` | Remove an instance by ID |

## Service: discovery

| Method | Description |
|---|---|
| `Discover(ctx, serviceName string) ([]*ServiceInstance, error)` | Every instance of a service |
| `DiscoverWithTags(ctx, serviceName string, tags []string) ([]*ServiceInstance, error)` | Instances that have all of the tags |
| `DiscoverHealthy(ctx, serviceName string) ([]*ServiceInstance, error)` | Instances whose status is `passing` |
| `SelectInstance(ctx, serviceName string, strategy LoadBalanceStrategy) (*ServiceInstance, error)` | One healthy instance |
| `GetServiceURL(ctx, serviceName, scheme string, strategy LoadBalanceStrategy) (string, error)` | One healthy instance as `scheme://address:port`. An empty scheme means `http` |
| `ListServices(ctx) ([]string, error)` | Every service name the backend knows |
| `Watch(ctx, serviceName string, onChange func([]*ServiceInstance)) error` | Call `onChange` with the full list whenever it changes |

## Service: backend access

| Method | Description |
|---|---|
| `Backend() Backend` | The underlying backend |
| `Health(ctx) error` | The backend's health |

`Name`, `Start` and `Stop` are lifecycle methods the container calls for you.

## Load balancing strategies

| Constant | Value | Status |
|---|---|---|
| `LoadBalanceRoundRobin` | `round_robin` | Works |
| `LoadBalanceRandom` | `random` | Works |
| `LoadBalanceLeastConnections` | `least_connections` | Falls back to round-robin |
| `LoadBalanceWeightedRoundRobin` | `weighted_round_robin` | Falls back to round-robin |

## ServiceInstance

`ServiceInstance` (an alias for `backends.ServiceInstance`) has `ID`, `Name`, `Version`, `Address`, `Port`, `Tags`, `Metadata`, `Status` and `LastHeartbeat`, plus:

| Method | Description |
|---|---|
| `URL(scheme string) string` | `scheme://address:port` |
| `HasTag(tag string) bool` | Whether the instance has a tag |
| `HasAllTags(tags []string) bool` | Whether it has every tag |
| `IsHealthy() bool` | `Status == HealthStatusPassing` |
| `GetMetadata(key string) (string, bool)` | One metadata value |

Health statuses: `HealthStatusPassing`, `HealthStatusWarning`, `HealthStatusCritical`, `HealthStatusUnknown`.

## Extension accessors

If you hold the `*discovery.Extension`, `Service()` returns the discovery service, `ServiceNode()` the FARP service node (nil until FARP has started), and `LocalServiceID()` the ID this app registered under.

## FARP routes

With `farp.enabled`, the extension registers:

| Route | Description |
|---|---|
| `GET /_farp/manifest` | The FARP manifest. 503 until the app has started |
| `GET /_farp/health` | FARP health. 503 until the app has started |
| `GET /_farp/schemas/:type` | The OpenAPI or AsyncAPI schema. 503 until the app has started |
| `GET /_farp/discovery` | This instance's ID, name, version, address, port, tags and metadata. 503 until the extension has started |

## Not used by the extension

`NewSchemaPublisher(config FARPConfig, app forge.App) *SchemaPublisher`, `ServiceRegistration`, `ServiceQuery`, `ServiceEvent` and the `ServiceEvent*` constants are exported, but the extension itself doesn't use them.
