## Where settings come from

The extension reads `extensions.discovery` from your config file, falling back to a top-level `discovery` key, over `DefaultConfig()`. Then it applies the options you passed to `NewExtension` on top, so an option wins over the file, including an explicit `false`. `NewExtensionWithConfig(cfg)` is `NewExtension(WithConfig(cfg))`: it replaces the whole config, file values included.

`enabled` must be a real boolean in the file. A string that doesn't parse as one fails registration. With `enabled: false` the extension registers nothing, so `forge.Inject[*discovery.Service]` fails.

## YAML example

```yaml title="config.yaml"
extensions:
  discovery:
    enabled: true
    backend: "consul"   # memory, consul, etcd, kubernetes, mdns, http (eureka isn't implemented)

    service:
      name: "orders"
      id: "orders-1"     # set this; see "Instance ID" below
      version: "1.0.0"
      address: ""        # empty means work it out, see below
      port: 8080
      tags: ["api", "v1"]
      metadata:
        team: "checkout"
      enable_auto_deregister: true

    health_check:
      enabled: true
      interval: "10s"
      timeout: "5s"

    watch:
      enabled: true
      services: ["payments"]

    consul:
      address: "127.0.0.1:8500"
      token: ""
      datacenter: "dc1"

    etcd:
      endpoints: ["127.0.0.1:2379"]
      dial_timeout: "5s"
      key_prefix: "/services"

    mdns:
      domain: "local."
      browse_timeout: "3s"
      ttl: 120

    farp:
      enabled: false
      auto_register: true
      gateway_url: ""
      endpoints:
        health: "/health"
        openapi: ""
        asyncapi: ""
        graphql: ""
        grpc_reflection: false
```

## Programmatic configuration

```go
ext := discovery.NewExtension(
	discovery.WithConsul("127.0.0.1:8500", consulToken),
	discovery.WithServiceName("orders"),
	discovery.WithServiceID("orders-1"),
	discovery.WithServiceTags("api", "v1"),
	discovery.WithHealthCheck(discovery.HealthCheckConfig{
		Enabled:  true,
		Interval: 10 * time.Second,
		Timeout:  5 * time.Second,
	}),
	discovery.WithFARPEnabled(true),
	discovery.WithFARPEndpoints(discovery.FARPEndpointsConfig{
		Health:  "/health",
		OpenAPI: "/openapi.json",
	}),
)
```

`WithHealthCheck` replaces the whole health check section, so set `Timeout` too. A zero timeout makes every check time out at once.

## Keys

| Key | Default | What it does |
|---|---|---|
| `enabled` | `true` | Turns the extension off without removing it |
| `backend` | `memory` | `memory`, `consul`, `etcd`, `kubernetes`, `mdns`, `http` or `eureka` (fails) |
| `service.name`, `id`, `version`, `address`, `port` | empty | This instance. See below |
| `service.tags`, `service.metadata` | empty | Stored with the registration. `metadata.scheme` changes the scheme in FARP URLs |
| `service.enable_auto_deregister` | `true` | Deregister on shutdown when FARP is off |
| `health_check.enabled` | `true` | Run the health loop |
| `health_check.interval`, `timeout` | `10s`, `5s` | How often to check, and how long a check may take |
| `watch.enabled`, `watch.services` | `false`, `[]` | Services to watch from start |
| `consul.address`, `token`, `datacenter`, `namespace` | `127.0.0.1:8500` | Consul agent and ACL settings |
| `consul.tls_enabled`, `tls_ca_file`, `tls_cert`, `tls_key` | off | Consul TLS |
| `etcd.endpoints`, `username`, `password`, `dial_timeout`, `key_prefix` | `127.0.0.1:2379`, `5s`, `/services` | etcd client |
| `kubernetes.namespace`, `in_cluster`, `kubeconfig_path`, `service_type`, `label_selector` | `default`, `true`, `ClusterIP` | Kubernetes API access and filtering |
| `mdns.domain`, `service_type`, `service_types`, `watch_interval`, `interface`, `ipv6`, `browse_timeout`, `ttl` | `local.`, `3s`, `120` | mDNS registration and browsing |
| `http.seeds`, `poll_interval`, `timeout` | `[]`, `10s`, `5s` | HTTP seed polling |
| `farp.enabled`, `auto_register`, `gateway_url` | `false`, `true`, empty | FARP routes, schema auto-detection and gateway push |
| `farp.schemas` | `[]` | Only each entry's `type` (`openapi` or `asyncapi`) is read |
| `farp.endpoints.health`, `openapi`, `asyncapi`, `graphql`, `grpc_reflection` | `/health` for health | Paths advertised in the manifest and registry metadata |
| `farp.exclude_internal_paths`, `collapse_service_tags`, `path_rules` | `true`, `false`, none | Schema filtering and tag grouping |

### Read but not used

These keys exist and are loaded, but nothing acts on them yet:

- `health_check.http`, `health_check.tcp`, `health_check.grpc` and `health_check.deregister_critical_service_after`. The loop always runs your app's health checks, and Consul's deregistration delay is fixed at one minute.
- `watch.tags`.
- `etcd.tls_enabled`, `tls_ca_file`, `tls_cert` and `tls_key`. The etcd client always connects without TLS.
- `farp.strategy`, `farp.capabilities` and `farp.endpoints.metrics`.
- `farp.schemas[].spec_version`, `location` and `content_type`.
- The whole `eureka` section, since the backend isn't implemented.

## Where the address comes from

When you leave `service.address` and `service.port` empty, the extension works them out:

| Field | Taken from, in order |
|---|---|
| Name | `FORGE_SERVICE_ID`, `service.name`, the app's name |
| Version | `service.version`, the app's version |
| Port | `service.port`, then the port in the app's `HTTPAddress` |
| Address | `service.address`, `FORGE_ADVERTISE_ADDR`, `POD_IP`, the host in the app's `HTTPAddress`, the machine's hostname, then `localhost` |
| Instance ID | `FORGE_INSTANCE_ID`, `<name>-<hostname>` when `FORGE_SERVICE_ID` is set, `service.id`, then a generated `<name>-<unix nanoseconds>` |

A wildcard listen address such as `0.0.0.0` or `::` is never advertised. IPv6 addresses keep their port and get brackets in FARP URLs.

### Instance ID

Set one. A generated ID changes every time the extension builds the instance, and the health loop builds it on every tick, so without a stable ID each tick adds a new entry to the registry and shutdown deregisters an ID that was never registered.

## Kubernetes

```yaml
extensions:
  discovery:
    backend: kubernetes
    service:
      name: api
    kubernetes:
      namespace: atlas-production
      in_cluster: true
```

Expose `POD_IP` through the downward API so the advertised address is the pod's IP. The Kubernetes backend doesn't register your app (Kubernetes owns that), and it needs RBAC permission to list Services in the namespace.

## Options

| Option | Effect |
|---|---|
| `WithEnabled(bool)` | Turn the extension on or off |
| `WithBackend(name)` | Pick a backend by name |
| `WithConsul(address, token)` | Select `consul` and set the agent and token |
| `WithEtcd(endpoints)` | Select `etcd` and set the endpoints |
| `WithKubernetes(namespace, inCluster)` | Select `kubernetes` |
| `WithMDNS(domain)` | Select `mdns`; an empty domain keeps `local.` |
| `WithHTTPSeeds(seeds...)`, `WithHTTPPollInterval(d)`, `WithHTTPTimeout(d)` | Select `http` and tune polling |
| `WithEureka(urls)` | Select `eureka`, which fails at startup |
| `WithService(ServiceConfig)` | Replace the whole service section |
| `WithServiceName`, `WithServiceID`, `WithServiceVersion` | Instance identity |
| `WithServiceAddress(address, port)` | Advertised address and port |
| `WithServiceTags(tags...)`, `WithServiceMetadata(map)` | Tags and metadata |
| `WithAutoDeregister(bool)` | Deregister on shutdown |
| `WithAppConfig(forge.AppConfig)` | Use this app config for name, version and `HTTPAddress` |
| `WithHealthCheck(HealthCheckConfig)` | Replace the health check section |
| `WithHTTPHealthCheck(endpoint, interval)` | Turn the loop on and set the interval. The endpoint isn't probed |
| `WithWatch(services, onChange)` | Watch these services from start with a callback |
| `WithFARP(FARPConfig)` | Replace the FARP section |
| `WithFARPEnabled`, `WithFARPAutoRegister`, `WithFARPGatewayURL` | FARP switches |
| `WithFARPSchemas(schemas...)`, `WithFARPEndpoints(cfg)` | Schemas and advertised endpoints |
| `WithFARPExcludeInternalPaths(bool)`, `WithFARPCollapseServiceTags(bool)`, `WithFARPPathRules(rules...)` | Schema filtering |
| `WithFARPStrategy`, `WithFARPCapabilities` | Stored, not used |
| `WithMDNSServiceType`, `WithMDNSServiceTypes`, `WithMDNSWatchInterval`, `WithMDNSBrowseTimeout`, `WithMDNSTTL`, `WithMDNSInterface`, `WithMDNSIPv6` | mDNS settings |
| `WithConfig(Config)` | Replace everything |
