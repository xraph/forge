## Overview

`github.com/xraph/forge/extensions/discovery` registers your app in a service registry when it starts, keeps its health status up to date, and deregisters it on shutdown. It puts a `*discovery.Service` in the container for finding other services by name or tag, with round-robin or random picks, and it can publish a FARP manifest that tells an API gateway about your routes and OpenAPI or AsyncAPI schemas.

Backends: `memory` (the default), `consul`, `etcd`, `kubernetes`, `mdns` and `http`. Eureka has config and an option, but it isn't implemented and startup fails if you pick it.

## What it registers

| Service | DI key | Type |
|---|---|---|
| Discovery service | `discovery` (also `discovery.Service`) | `*discovery.Service` |

There are no `Get` helpers in this package. Resolve it with `forge.Inject[*discovery.Service](app.Container())` or take it as a constructor parameter.

## Quick start

```bash
go get github.com/xraph/forge@latest
go get github.com/xraph/forge/extensions/discovery@latest
```

This registers an `orders` service in the in-memory registry and adds a route that looks services up:

```go
package main

import (
	"log"
	"net/http"

	"github.com/xraph/forge"
	"github.com/xraph/forge/extensions/discovery"
)

func main() {
	app := forge.NewApp(forge.AppConfig{
		Name:        "orders",
		Version:     "1.0.0",
		HTTPAddress: ":8080",
		Extensions: []forge.Extension{
			discovery.NewExtension(
				discovery.WithBackend("memory"),
				discovery.WithServiceName("orders"),
				discovery.WithServiceID("orders-1"),
				discovery.WithServiceTags("api", "v1"),
			),
		},
	})

	err := app.Router().GET("/instances/:service", func(ctx forge.Context) error {
		svc, err := forge.Inject[*discovery.Service](app.Container())
		if err != nil {
			return err
		}

		instances, err := svc.Discover(ctx.Context(), ctx.Param("service"))
		if err != nil {
			return err
		}

		return ctx.JSON(http.StatusOK, instances)
	})
	if err != nil {
		log.Fatal(err)
	}

	if err := app.Run(); err != nil {
		log.Fatal(err)
	}
}
```

```bash
curl http://localhost:8080/instances/orders
```

The memory registry lives inside one process, so use it for development and tests. Swap `WithBackend("memory")` for `WithConsul("127.0.0.1:8500", token)` or another backend and the rest of the code stays the same.

Always give each replica a stable instance ID, with `WithServiceID`, `service.id` or the `FORGE_INSTANCE_ID` environment variable. Without one, the extension makes up a new ID (`<name>-<unix nanoseconds>`) every time it builds the instance, and the health loop, which re-registers every `health_check.interval`, adds a fresh entry to the registry on every tick. Shutdown then deregisters an ID that was never registered.

## Looking up other services

```go
svc, err := forge.Inject[*discovery.Service](app.Container())
if err != nil {
	return err
}

all, err := svc.Discover(ctx, "payments")
v2, err := svc.DiscoverWithTags(ctx, "payments", []string{"v2"})
healthy, err := svc.DiscoverHealthy(ctx, "payments")

instance, err := svc.SelectInstance(ctx, "payments", discovery.LoadBalanceRoundRobin)
url, err := svc.GetServiceURL(ctx, "payments", "http", discovery.LoadBalanceRandom)

err = svc.Watch(ctx, "payments", func(instances []*discovery.ServiceInstance) {
	log.Printf("payments now has %d instances", len(instances))
})
```

## FARP

FARP is the Forge API gateway registration protocol, implemented in [xraph/farp](https://github.com/xraph/farp). Turn it on and the extension adds `/_farp/manifest`, `/_farp/health`, `/_farp/schemas/:type` and `/_farp/discovery` to your app, and puts `farp.*` keys in the instance metadata it registers (mDNS TXT records, Consul service metadata, etcd values):

```go
discovery.NewExtension(
	discovery.WithBackend("mdns"),
	discovery.WithServiceName("users"),
	discovery.WithServiceID("users-1"),
	discovery.WithFARPEnabled(true),
	discovery.WithFARPGatewayURL("http://localhost:7903"),
)
```

The manifest is built in a `PhaseAfterStart` hook, after every extension has started, so it sees routes that other extensions add during their own start. With `gateway_url` set, the extension also posts its registration to the gateway once the HTTP server is listening. See [Features](/docs/extensions/discovery/features#farp) for the details.

## Runtime notes

- `memory` is local to one process and shares nothing between nodes.
- `kubernetes` doesn't register your app (Kubernetes owns that), and `http` only keeps your registration in this process. Both still discover other services.
- `etcd` accepts the `tls_*` keys but doesn't apply them yet, so it always connects without TLS.
- `LoadBalanceLeastConnections` and `LoadBalanceWeightedRoundRobin` exist as constants but fall back to round-robin.
- With mDNS, the service name sets the service type (`_<name>._tcp`) unless you set `WithMDNSServiceType`.
