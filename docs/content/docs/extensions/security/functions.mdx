## Extension

| Function | Description |
|---|---|
| `NewExtension(opts ...ConfigOption) *Extension` | Create the extension. It satisfies `forge.Extension` and `forge.MiddlewareExtension` |
| `NewExtensionWithConfig(config Config) forge.Extension` | Same as `NewExtension(WithConfig(config))` |
| `DefaultConfig() Config` | The defaults for every section |
| `(*Extension).Middlewares() []forge.Middleware` | The auto-applied middleware, built during `Register` |

Accessors, all `nil` until the extension has registered: `SessionStore()`, `CookieManager()`, `CSRFProtection()`, `RateLimiter()`, `SecurityHeadersManager()`, `PasswordHasher()`, `JWTManager()`, `CORSManager()`, `APIKeyManager()`, `AuditLogger()`.

## Sessions

| Function | Description |
|---|---|
| `NewSession(userID string, ttl time.Duration) (*Session, error)` | A session with a fresh random ID |
| `GenerateSessionID() (string, error)` | 32 random bytes, base64url-encoded |
| `NewInMemorySessionStore(logger, metrics) *InMemorySessionStore` | The store the extension uses |
| `SessionMiddleware(opts SessionMiddlewareOptions) forge.Middleware` | Loads the session from its cookie and stores it with `ctx.Set("session", ...)` |
| `CreateSession(ctx, w, userID, store, cookieManager, config SessionConfig, metadata map[string]any) (*Session, error)` | Creates and stores a session and sets its cookie |
| `GetSessionFromForgeContext(ctx forge.Context) (*Session, bool)` | Reads what `SessionMiddleware` stored |
| `MustGetSessionFromForgeContext(ctx forge.Context) *Session` | Same, panics when there is none |
| `RequireSession(unauthorized forge.Handler) forge.Middleware` | Calls your handler when there is no session. `RequireSessionFunc` is an alias |
| `RequireSessionSimple() forge.Middleware` | Answers 401 when there is no session |
| `GetSession(ctx context.Context)`, `MustGetSession(ctx)` | Read the request context under `SessionContextKey{}`, which nothing sets |
| `DestroySession(ctx, w, store, cookieManager, cookieName) error` | Reads the session through `GetSession`, so today it returns nil without deleting anything |
| `UpdateSession(ctx, store, ttl) error` | Reads the session through `GetSession`, so today it returns `ErrSessionNotFound` |

`SessionStore` methods: `Create(ctx, session, ttl) error`, `Get(ctx, id) (*Session, error)`, `Update(ctx, session, ttl) error`, `Delete(ctx, id) error`, `DeleteByUserID(ctx, userID) error`, `Touch(ctx, id, ttl) error`, `Cleanup(ctx) (int, error)`, `Count(ctx) (int64, error)`, `Connect(ctx) error`, `Disconnect(ctx) error`, `Ping(ctx) error`.

`Session` methods: `GetID`, `GetUserID`, `GetData(key) (any, bool)`, `SetData(key, value)`, `DeleteData(key)`, `GetCreatedAt`, `GetExpiresAt`, `GetLastAccessedAt`, `IsExpired`, `IsValid`, `Touch`.

## Cookies

| `(*CookieManager).SetCookie(w, name, value string, opts *CookieOptions)` | Empty fields fall back to the defaults. `nil` uses the defaults |
| `(*CookieManager).GetCookie(r, name) (string, error)` | `ErrCookieNotFound` when absent |
| `(*CookieManager).DeleteCookie(w, name string, opts *CookieOptions)` | Expires the cookie |
| `(*CookieManager).HasCookie(r, name) bool` | |
| `(*CookieManager).GetAllCookies(r) []*http.Cookie` | |

`SameSiteMode` values: `SameSiteDefault`, `SameSiteLax`, `SameSiteStrict`, `SameSiteNone`.

## JWT

| Function | Description |
|---|---|
| `NewJWTManager(config JWTConfig, logger) (*JWTManager, error)` | Fails without a signing key for an `HS*` method |
| `DefaultJWTConfig() JWTConfig` | |
| `(*JWTManager).GenerateToken(claims *JWTClaims) (string, error)` | Fills in the registered claims and signs |
| `(*JWTManager).GenerateRefreshToken(userID string) (string, error)` | A token that lasts `RefreshTTL` |
| `(*JWTManager).ValidateToken(token string) (*JWTClaims, error)` | `ErrJWTInvalid`, `ErrJWTExpired` or `ErrJWTNotYetValid` |
| `JWTMiddleware(jwtManager *JWTManager) forge.Middleware` | Verifies the token and stores the claims with `ctx.Set("jwt_claims", ...)` |
| `GetJWTClaims(ctx forge.Context) (*JWTClaims, bool)` | Reads what `JWTMiddleware` stored |
| `RequireRoles(roles ...string) forge.Middleware` | Lets the request through when the claims hold any one of the roles |
| `GetJWTClaimsFromStdContext(ctx context.Context) (*JWTClaims, bool)` | Reads the request context, where nothing stores claims |
