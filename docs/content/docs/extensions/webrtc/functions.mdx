## Extension

| Function | Description |
|---|---|
| `New(streamingExt *streaming.Extension, config Config, opts ...ConfigOption) (*Extension, error)` | Applies the options and validates |
| `DefaultConfig() Config` | Mesh topology and two Google STUN servers |
| `(*Extension).CreateCallRoom(ctx, roomID string, opts streaming.RoomOptions) (CallRoom, error)` | `opts.ID` is required |
| `(*Extension).GetCallRoom(roomID string) (CallRoom, error)` | `ErrRoomNotFound` for an unknown ID |
| `(*Extension).GetCallRooms() []CallRoom` | |
| `(*Extension).DeleteCallRoom(ctx, roomID string) error` | Closes every peer in the room |
| `(*Extension).JoinCall(ctx, roomID, userID string, opts *JoinOptions) (PeerConnection, error)` | Joins and updates the call metrics |
| `(*Extension).LeaveCall(ctx, roomID, userID string) error` | |
| `(*Extension).GetConfig() Config` | |
| `(*Extension).GetSignalingManager() SignalingManager` | Set once the extension has registered |
| `(*Extension).GetSFURouter() SFURouter` | nil in mesh mode |
| `(*Extension).GetQualityMonitor() QualityMonitor`, `GetRecorder() Recorder` | Always nil today |
| `(*Extension).RegisterRoutes(router forge.Router) error` | Mounts the unfinished signaling WebSocket at `/webrtc/signal/{roomID}` |

`*Extension` also has the lifecycle methods `Name`, `Version`, `Description`, `Dependencies` (`streaming`), `Register`, `Start`, `Stop` and `Health`.

## CallRoom

| Method | Description |
|---|---|
| `ID() string`, `Name() string` | The ID is prefixed with `mesh-` or `sfu-` |
| `JoinCall(ctx, userID string, opts *JoinOptions) (PeerConnection, error)` | |
| `Leave(ctx, userID string) error` | `ErrNotInRoom` when the user isn't there |
| `GetPeer(userID string) (PeerConnection, error)`, `GetPeers() []PeerConnection` | |
| `GetParticipants() []Participant` | Only `UserID`, `JoinedAt` and, in SFU rooms, `Quality` are set |
| `MuteUser`, `UnmuteUser`, `EnableVideo`, `DisableVideo` `(ctx, userID string) error` | Switch the server's send tracks for that user |
| `StartScreenShare(ctx, userID string, track MediaTrack) error`, `StopScreenShare(ctx, userID string) error` | Return `ErrNotImplemented` |
| `GetQuality(ctx) (*CallQuality, error)` | Returns `ErrNotImplemented` |
| `Close(ctx) error` | |

`NewMeshCallRoom(streamingRoom, config, signaling, logger, metrics) CallRoom`, `NewMeshCallRoomFromOptions(opts, config, signaling, logger, metrics) (CallRoom, error)` and `NewSFUCallRoomFromOptions(opts, config, signaling, router, logger, metrics) (CallRoom, error)` build rooms outside the extension. `CreateCallRoom` is the usual way in.

## PeerConnection

| Method | Description |
|---|---|
| `ID() string`, `UserID() string`, `State() ConnectionState` | |
| `CreateOffer(ctx) (*SessionDescription, error)` | Sets the local description and waits up to five seconds for ICE gathering |
| `CreateAnswer(ctx) (*SessionDescription, error)` | Same, for an answer |
| `SetLocalDescription(ctx, sdp *SessionDescription) error` | |
| `SetRemoteDescription(ctx, sdp *SessionDescription) error` | |
| `AddICECandidate(ctx, candidate *ICECandidate) error` | `ErrInvalidCandidate` for an out-of-range m-line index |
| `AddTrack(ctx, track MediaTrack) error`, `RemoveTrack(ctx, trackID string) error`, `GetTracks() []MediaTrack` | |
| `GetStats(ctx) (*PeerStats, error)` | |
| `Close(ctx) error` | |
| `OnICECandidate`, `OnTrack`, `OnConnectionStateChange`, `OnDataChannel` | Each replaces the previous handler |

`NewPeerConnection(id, userID string, config Config, logger forge.Logger) (PeerConnection, error)` creates one outside a room. `NewLocalTrack(kind TrackKind, id, label string, logger forge.Logger) (MediaTrack, error)` creates an Opus or VP8 send track.

## SignalingManager

| Method | Description |
|---|---|
| `SendOffer(ctx, roomID, peerID string, offer *SessionDescription) error` | Broadcasts a `webrtc.offer` message to the streaming room |
| `SendAnswer(ctx, roomID, peerID string, answer *SessionDescription) error` | `webrtc.answer` |
| `SendICECandidate(ctx, roomID, peerID string, candidate *ICECandidate) error` | `webrtc.ice_candidate` |
| `OnOffer`, `OnAnswer`, `OnICECandidate` | Store a handler that nothing calls yet |
| `Start(ctx) error`, `Stop(ctx) error` | |

`NewSignalingManager(streamingExt *streaming.Extension, logger forge.Logger) SignalingManager` creates one. The message type constants are `MessageTypeOffer`, `MessageTypeAnswer` and `MessageTypeICECandidate`.
