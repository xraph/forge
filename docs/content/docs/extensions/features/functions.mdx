## Extension entry points

| Function | Description |
|---|---|
| `NewExtension(opts ...ConfigOption) forge.Extension` | The extension, with options applied over `DefaultConfig()` |
| `NewExtensionWithConfig(config Config) forge.Extension` | The extension with a complete config |
| `DefaultConfig() Config` | The defaults |

The options are listed on the [Configuration](/docs/extensions/features/configuration#options) page.

## DI helpers

| Function | Description |
|---|---|
| `Get(container forge.Container) (*Service, error)` | Resolve the service |
| `MustGet(container forge.Container) *Service` | Same, panics on error |
| `GetFromApp(app forge.App) (*Service, error)` | Resolve from an app |
| `MustGetFromApp(app forge.App) *Service` | Same, panics on error |

## Service: flag evaluation

| Method | Description |
|---|---|
| `IsEnabled(ctx, flagKey string, userCtx *UserContext) bool` | A boolean flag, `false` when undefined |
| `IsEnabledWithDefault(ctx, flagKey string, userCtx *UserContext, defaultValue bool) bool` | A boolean flag with your fallback |
| `GetString(ctx, flagKey string, userCtx *UserContext, defaultValue string) string` | A string flag |
| `GetInt(ctx, flagKey string, userCtx *UserContext, defaultValue int) int` | An `int` flag |
| `GetFloat(ctx, flagKey string, userCtx *UserContext, defaultValue float64) float64` | A `float64` flag |
| `GetJSON(ctx, flagKey string, userCtx *UserContext, defaultValue any) any` | Any value, returned as stored |
| `GetAllFlags(ctx, userCtx *UserContext) (map[string]any, error)` | Every defined flag, evaluated for the user |
| `Refresh(ctx) error` | Call the provider's `Refresh` once (a no-op for `local`) |
| `Health(ctx) error` | The provider's health |

The service also has `Name`, `Start` and `Stop`, which the container calls for you.

## UserContext

| Function | Description |
|---|---|
| `NewUserContext(userID string) *UserContext` | A user context with an ID |
| `uc.WithEmail(email string) *UserContext` | Set the email |
| `uc.WithName(name string) *UserContext` | Set the name |
| `uc.WithGroups(groups []string) *UserContext` | Set the groups |
| `uc.WithAttribute(key string, value any) *UserContext` | Set a custom attribute |
| `uc.WithIP(ip string) *UserContext` | Set the IP address |
| `uc.WithCountry(country string) *UserContext` | Set the country |

| `uc.GetAttributeString(key string) (string, error)` | A custom attribute as a string, or an error when it's missing or not a string |

## Provider interface

Implement `features.Provider` to build your own provider. The extension can't take one yet (it only builds providers by name), but you can pass it to `NewService(config, provider, logger)` yourself.

| Method | Description |
|---|---|
| `Name() string` | Provider name |
| `Initialize(ctx) error` | Called by the service's `Start` |
| `IsEnabled(ctx, flagKey, userCtx, defaultValue bool) (bool, error)` | Evaluate a boolean flag |
| `GetString(ctx, flagKey, userCtx, defaultValue string) (string, error)` | String value |
| `GetInt(ctx, flagKey, userCtx, defaultValue int) (int, error)` | Integer value |
| `GetFloat(ctx, flagKey, userCtx, defaultValue float64) (float64, error)` | Float value |
| `GetJSON(ctx, flagKey, userCtx, defaultValue any) (any, error)` | Any value |
| `GetAllFlags(ctx, userCtx) (map[string]any, error)` | Every flag |
| `Refresh(ctx) error` | Reload from the source |
| `Close() error` | Release resources |
| `Health(ctx) error` | Health check |

`NewLocalProvider(config LocalProviderConfig, defaults map[string]any) Provider` builds the local provider. `NewLaunchDarklyProvider`, `NewUnleashProvider`, `NewFlagsmithProvider` and `NewPostHogProvider` exist but always return an error.

## Unused types

`FlagValue`, `EvaluationResult` and `FlagEvaluationEvent` are exported, but nothing in the extension produces or consumes them.
