## Extension entry points

| Function | Description |
|---|---|
| `NewExtension(opts ...ConfigOption) forge.Extension` | The extension with options |
| `NewExtensionWithConfig(config Config) forge.Extension` | The extension with a complete config |
| `DefaultConfig() Config` | The defaults |

The options are listed on the [Configuration](/docs/extensions/grpc/configuration#options) page.

## Resolving the server

There are no `Get` helpers. Use Forge's DI:

```go
svc, err := forge.Inject[*grpcext.GRPCService](app.Container()) // also registered as "grpc"
srv, err := forge.Inject[grpcext.GRPC](app.Container())         // the same server
```

## Constructors

| Function | Description |
|---|---|
| `NewGRPCService(config Config, logger forge.Logger, metrics forge.Metrics) (*GRPCService, error)` | The service the extension registers. Validates the config |
| `NewGRPCServer(config Config, logger forge.Logger, metrics forge.Metrics) GRPC` | A bare server you start yourself with `Start(ctx, addr)` |

## `GRPCService`

| Method | Description |
|---|---|
| `Server() GRPC` | The server |
| `Start(ctx) error` | Start the server on the configured address. The extension calls it |
| `Stop(ctx) error` | `GracefulStop`, then `Stop` if that fails. The extension calls it |
| `Health(ctx) error` | Whether the server exists |
| `RegisterService`, `AddUnaryInterceptor`, `AddStreamInterceptor`, `RegisterHealthChecker`, `GetServer`, `IsRunning`, `GetStats`, `GetServices`, `Ping` | Pass through to the server |

## `GRPC`: service registration

| Method | Description |
|---|---|
| `RegisterService(desc *grpc.ServiceDesc, impl any) error` | Register a service. Not reliable on the managed server, see the [known issue](/docs/extensions/grpc#known-issue-registering-your-own-services) |
| `GetServices() []ServiceInfo` | Registered services and their methods |

## `GRPC`: lifecycle

| Method | Description |
|---|---|
| `Start(ctx, addr string) error` | Build a fresh `grpc.Server` with the configured options and serve on `addr`. Does nothing if already running |
| `Stop(ctx) error` | Hard stop. `ErrNotStarted` when not running |
| `GracefulStop(ctx) error` | Drain, then stop. `ErrNotStarted` when not running |
| `IsRunning() bool` | Whether it's serving |
| `Ping(ctx) error` | `ErrNotStarted` when not running |
| `GetServer() *grpc.Server` | The underlying grpc-go server |

## `GRPC`: interceptors

| Method | Description |
|---|---|
| `AddUnaryInterceptor(interceptor grpc.UnaryServerInterceptor)` | Appended to the chain on the next `Start`. Never runs on a server that's already running |
| `AddStreamInterceptor(interceptor grpc.StreamServerInterceptor)` | Same, for streams |

## `GRPC`: health and stats

| Method | Description |
|---|---|
| `RegisterHealthChecker(service string, checker HealthChecker)` | Answer `NOT_SERVING` for `service` when `checker.Check` fails |
| `GetStats() ServerStats` | Start time, RPC counts and active streams |

## Key types

### `ServerStats`

| Field | Type | Purpose |
|---|---|---|
| `StartTime` | `int64` | Unix seconds when the server last started |
| `TotalConnections` | `int64` | Never updated, always zero |
| `ActiveStreams` | `int64` | Streams in flight |
| `RPCsStarted`, `RPCsSucceeded`, `RPCsFailed` | `int64` | Unary call counts |

The counts come from the metrics interceptor and stay at zero with metrics off.

### `ServiceInfo`

| Field | Type | Purpose |
|---|---|---|
| `Name` | `string` | Fully qualified service name |
| `Methods` | `[]MethodInfo` | Service methods |
| `Description` | `string` | Always empty |

### `MethodInfo`

| Field | Type | Purpose |
|---|---|---|
| `Name` | `string` | Method name |
| `IsClientStream` | `bool` | Client streams requests |
| `IsServerStream` | `bool` | Server streams responses |
| `InputType`, `OutputType` | `string` | Always empty; grpc-go's service info doesn't carry them |

### `HealthChecker`

```go
type HealthChecker interface {
	Check(ctx context.Context) error
}
```
