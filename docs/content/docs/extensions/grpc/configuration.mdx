## YAML configuration

The extension reads `extensions.grpc` from your config file, falling back to a top-level `grpc` key. Keys are snake_case.

```yaml title="config.yaml"
extensions:
  grpc:
    address: ":50051"
    max_recv_msg_size: 4194304   # 4 MB
    max_send_msg_size: 4194304   # 4 MB
    max_concurrent_streams: 0    # 0 means no limit
    connection_timeout: "120s"

    keepalive:
      time: "2h"
      timeout: "20s"
      enforcement_policy: true
      min_time: "5m"
      permit_without_stream: false

    enable_tls: false
    tls_cert_file: "/path/to/server.crt"
    tls_key_file: "/path/to/server.key"
    tls_ca_file: "/path/to/ca.crt"
    client_auth: false           # true for mTLS

    enable_health_check: true
    enable_reflection: true

    enable_metrics: true
    enable_tracing: true         # placeholder, writes a debug line
    enable_logging: true
```

## Programmatic configuration

```go
ext := grpcext.NewExtension(
	grpcext.WithAddress(":9090"),
	grpcext.WithTLS("server.crt", "server.key", "ca.crt"),
	grpcext.WithClientAuth(true),
	grpcext.WithMaxMessageSize(10 * 1024 * 1024), // 10 MB
	grpcext.WithMaxConcurrentStreams(100),
)
```

## Precedence

The extension starts from `DefaultConfig()`, applies the config file section, then applies the fields you set in code. A field counts as set in code when it differs from the default, so `WithReflection(false)` turns reflection off even when your file says `enable_reflection: true`. The one thing the loader can't see is an option set to exactly its default: that looks like no option, and the file wins for that field.

`WithRequireConfig(true)` makes a missing section an error at startup. `WithConfig(cfg)` replaces the programmatic config wholesale, and `NewExtensionWithConfig(cfg)` does the same.

## Config struct reference

### `Config`

| Field | YAML key | Default | Description |
|---|---|---|---|
| `Address` | `address` | `":50051"` | TCP listen address. Required |
| `MaxRecvMsgSize` | `max_recv_msg_size` | `4194304` | Receive limit in bytes |
| `MaxSendMsgSize` | `max_send_msg_size` | `4194304` | Send limit in bytes |
| `MaxConcurrentStreams` | `max_concurrent_streams` | `0` | Streams per connection, `0` for no limit |
| `ConnectionTimeout` | `connection_timeout` | `120s` | Time allowed for a new connection's handshake |
| `Keepalive` | `keepalive` | see below | Keepalive settings |
| `EnableTLS` | `enable_tls` | `false` | Serve TLS. Needs `tls_cert_file` and `tls_key_file` |
| `TLSCertFile` | `tls_cert_file` | `""` | Server certificate |
| `TLSKeyFile` | `tls_key_file` | `""` | Server private key |
| `TLSCAFile` | `tls_ca_file` | `""` | CA for client certificates. Read only when `client_auth` is on |
| `ClientAuth` | `client_auth` | `false` | Require and verify client certificates. Needs `tls_ca_file` |
| `EnableHealthCheck` | `enable_health_check` | `true` | Register `grpc.health.v1.Health` |
| `EnableReflection` | `enable_reflection` | `true` | Register server reflection |
| `EnableMetrics` | `enable_metrics` | `true` | Metrics interceptors |
| `EnableTracing` | `enable_tracing` | `true` | Placeholder tracing interceptor |
| `EnableLogging` | `enable_logging` | `true` | Logging interceptors |
| `RequireConfig` | none | `false` | Set with `WithRequireConfig` |

If TLS is configured but the files can't be loaded, the server starts in plaintext and logs `failed to load TLS credentials`.

### `KeepaliveConfig`

| Field | YAML key | Default | Description |
|---|---|---|---|
| `Time` | `time` | `2h` | Ping interval for idle connections. Also the maximum idle time; twice it is the maximum connection age |
| `Timeout` | `timeout` | `20s` | Ping ack timeout, and the grace period after the maximum age |
| `EnforcementPolicy` | `enforcement_policy` | `true` | Enforce `min_time` on client pings |
| `MinTime` | `min_time` | `5m` | Minimum interval between client pings |
| `PermitWithoutStream` | `permit_without_stream` | `false` | Allow client pings with no active stream |

## Options

| Function | Description |
|---|---|
| `WithAddress(addr string)` | Listen address |
| `WithMaxMessageSize(size int)` | Receive and send limits |
| `WithMaxConcurrentStreams(maxStreams uint32)` | Streams per connection |
| `WithTLS(certFile, keyFile, caFile string)` | Turn TLS on with these files |
| `WithClientAuth(enable bool)` | Require client certificates |
| `WithHealthCheck(enable bool)` | Health service |
| `WithReflection(enable bool)` | Server reflection |
| `WithMetrics(enable bool)` | Metrics interceptors |
| `WithTracing(enable bool)` | Tracing interceptor |
| `WithRequireConfig(require bool)` | Fail when the config section is missing |
| `WithConfig(config Config)` | Replace the whole config |

`connection_timeout`, `keepalive` and `enable_logging` have no option. Set them in the file or through `WithConfig`.
