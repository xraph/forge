## Extension entry points

| Function | Description |
|---|---|
| `NewExtension(opts ...ConfigOption) forge.Extension` | Creates the extension from `DefaultConfig()` plus your options |
| `NewExtensionWithConfig(config Config) forge.Extension` | Same as `NewExtension(WithConfig(config))` |
| `DefaultConfig() Config` | The defaults on the configuration page |
| `(*Config) Validate() error` | The checks `Register` runs |

The option helpers are on the [configuration page](/docs/extensions/consensus/configuration#programmatic-configuration).

## Extension methods

`NewExtension` returns a `forge.Extension`. Assert it to `*consensus.Extension` to reach these:

| Method | Returns |
|---|---|
| `Service() *Service` | The consensus service |
| `IsLeader() bool`, `GetLeader() string`, `GetRole() NodeRole` | Leadership state of this node |
| `GetStats() ConsensusStats` | Live numbers from the Raft node |
| `GetClusterInfo() ClusterInfo` | The members of the current configuration and the leader |
| `Apply(ctx, cmd Command) error` | Writes through the leader. A not-leader error elsewhere |
| `Read(ctx, query any) (any, error)` | Queries this node's state machine |
| `Metrics() map[string]any` | The stats as a flat map |
| `Reload(ctx) error` | Reloads config, see [hot reload](/docs/extensions/consensus/configuration#hot-reload) |
| `Health(ctx) error` | The service's `HealthCheck` |

## Service

`*consensus.Service` is the extension's `ConsensusService`. `NewConsensusService(config Config, logger forge.Logger, metrics forge.Metrics) (*Service, error)` builds one on its own. It returns an error wrapping `ErrInvalidConfig` for settings it can't honour: storage `pebble` or `postgres`, or a discovery type other than `static`.

| Method | What it does |
|---|---|
| `Start(ctx) error` | Builds and starts storage, the transport, the state machine and the Raft node, then the health and metrics loops. A second call returns `ErrAlreadyStarted` |
| `Stop(ctx) error` | Stops the loops, the Raft node, the transport and storage |
| `IsLeader() bool`, `GetLeader() string`, `GetRole() NodeRole`, `GetTerm() uint64` | The Raft node's current state |
| `Apply(ctx, cmd Command) error` | On the leader, sends `cmd` as JSON through the log and returns once it is committed and applied. A not-leader error elsewhere, `raft.ErrProposalDropped` if a leadership change dropped it |
| `Read(ctx, query any) (any, error)` | Queries this node's state machine. Not linearizable |
| `Snapshot(ctx) error` | Snapshots the state machine and compacts the log |
| `AddNode(ctx, nodeID, address string, port int) error` | On the leader, adds a server started with `join`, as a learner and then a voter |
| `RemoveNode(ctx, nodeID string) error` | On the leader, removes a server, the leader included |
| `TransferLeadership(ctx, targetNodeID string) error` | On the leader, hands leadership to a voter, or fails with `raft.ErrLeadershipTransferFailed` |
| `StepDown(ctx) error` | The leader returns to follower |
| `ReencryptStorage() (int, error)` | Rewrites stored values that aren't under the active encryption key and returns how many. `ErrStorageNotEncrypted` without encryption |
| `GetStats() ConsensusStats`, `GetClusterInfo() ClusterInfo` | Stats and membership |
| `HealthCheck(ctx) error` | `nil` while the node has quorum, `no quorum` otherwise, `ErrNotStarted` before `Start` |
| `GetHealthStatus(ctx) HealthStatus` | Per-check details |
| `UpdateConfig(ctx, config Config) error` | Validates, then copies the `observability`, `health` and `admin_api` sections |
| `GetRaftNode()`, `GetStateMachine()`, `GetTransport()`, `GetStorage()` | The running components, `nil` before `Start` |
| `GetClusterManager()` | A `ClusterManager` backed by the Raft configuration. `UpdateNode` on it returns an error |
| `GetDiscovery()` | `nil`. The service doesn't run a discovery backend |

## LeadershipChecker

| Function or method | Description |
|---|---|
| `NewLeadershipChecker(service ConsensusService) *LeadershipChecker` | Wraps a service |
| `IsLeader() bool`, `GetLeader() string` | Pass through to the service |
| `RequireLeader() error` | A not-leader error naming the leader, or `nil` on the leader |
| `RequireQuorum() error` | `ErrNoQuorum`, or `nil` when the cluster has quorum |

## Key types

| Type | Fields |
|---|---|
| `Command` | `Type string`, `Payload map[string]any` |
| `LogEntry` | `Index`, `Term`, `Type EntryType`, `Data []byte`, `Created` |
| `Snapshot` | `Index`, `Term`, `Data []byte`, `Size`, `Created`, `Checksum` |
| `PeerConfig` | `ID`, `Address`, `Port` |
| What `raft.Node.Configuration()` returns | `Members`, each with `ID`, `Address`, `Port` and `Voter`. The type lives in the module's `internal` package and isn't re-exported, so you can use the value but not name its type |
| `ClusterInfo` | `ID`, `Leader`, `Term`, `Nodes []NodeInfo`, `TotalNodes`, `ActiveNodes`, `HasQuorum`, `CommitIndex`, `LastApplied` |
| `NodeInfo` | `ID`, `Address`, `Port`, `Role`, `Status`, `Term`, `LastHeartbeat`, `Metadata` |
| `HealthStatus` | `Healthy`, `Status`, `Leader`, `HasQuorum`, `TotalNodes`, `ActiveNodes`, `Details []HealthCheck`, `LastCheck`, `Checks` |
| `RaftStats` | `NodeID`, `Role`, `Term`, `Leader`, `CommitIndex`, `LastApplied`, `LastLogIndex`, `LastLogTerm`, `VotedFor`, `LastHeartbeat` |

`ConsensusStats` is listed on the [features page](/docs/extensions/consensus/features#statistics).

## Constants

| Group | Values |
|---|---|
| `NodeRole` | `RoleFollower`, `RoleCandidate`, `RoleLeader` (`"follower"`, `"candidate"`, `"leader"`) |
| `NodeStatus` | `StatusActive`, `StatusInactive`, `StatusSuspected`, `StatusFailed` |
| `EntryType` | `EntryNormal`, `EntryConfig`, `EntryBarrier`, `EntryNoop` |
| `MessageType` | `MessageTypeAppendEntries`, `MessageTypeRequestVote`, `MessageTypeInstallSnapshot`, `MessageTypeTimeoutNow`, their `...Response` counterparts, and `MessageTypeHeartbeat` |
| `NodeChangeType` | `NodeChangeTypeAdded`, `NodeChangeTypeRemoved`, `NodeChangeTypeUpdated` |
| `BatchOpType` | `BatchOpSet`, `BatchOpDelete` |
| Container names | `ServiceKey` (`consensus`), `ServiceKeyLegacy` (`consensus:service`), `ClusterManagerKey`, `RaftNodeKey`, `StateMachineKey`, `LeadershipCheckerKey` |

The event types (`ConsensusEventNodeStarted` and 32 more, each a `consensus.*` string) are exported too. The extension only emits `ConsensusEventNodeStarted`, `ConsensusEventNodeStopped` and `ConsensusEventConfigReloaded`.

## Errors

The sentinels and helpers are listed on the [features page](/docs/extensions/consensus/features#errors), including the `raft`, `storage` and `transport` ones: `raft.ErrProposalDropped`, `raft.ErrConfigChangeInProgress`, `raft.ErrLeadershipTransferInProgress`, `raft.ErrLeadershipTransferFailed`, `raft.ErrLearnerNotCaughtUp`, the `storage` encryption errors, `transport.ErrProtocolVersion` and `transport.ErrMessageTooLarge`.

| Function | Description |
|---|---|
| `NewNotLeaderError(nodeID, leaderID string)` | Not-leader error carrying both IDs |
| `NewNoLeaderError()` | No-leader error |
| `NewTimeoutError(operation string)` | Timeout error |
| `NewNoQuorumError(required, available int)` | No-quorum error carrying the counts |
| `NewStaleTermError(current, received uint64)` | Stale-term error carrying both terms |
| `IsNotLeaderError`, `IsNoLeaderError`, `IsNoQuorumError`, `IsStaleTermError` | `errors.Is` checks |
| `IsRetryable(err)`, `IsFatal(err)` | Classify an error |
