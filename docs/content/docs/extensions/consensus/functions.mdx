## Extension entry points

| Function | Description |
|---|---|
| `NewExtension(opts ...ConfigOption) forge.Extension` | Creates the extension from `DefaultConfig()` plus your options |
| `NewExtensionWithConfig(config Config) forge.Extension` | Same as `NewExtension(WithConfig(config))` |
| `DefaultConfig() Config` | The defaults on the configuration page |
| `(*Config) Validate() error` | The checks `Register` runs |

The option helpers are on the [configuration page](/docs/extensions/consensus/configuration#programmatic-configuration).

## Extension methods

`NewExtension` returns a `forge.Extension`. Assert it to `*consensus.Extension` to reach these:

| Method | Returns |
|---|---|
| `Service() *Service` | The consensus service |
| `IsLeader() bool` | Always `false` today |
| `GetLeader() string` | Always `""` today |
| `GetRole() NodeRole` | Always `RoleFollower` today |
| `GetStats() ConsensusStats` | Mostly zero today |
| `GetClusterInfo() ClusterInfo` | Empty today |
| `Apply(ctx, cmd Command) error` | Always a not-leader error today |
| `Read(ctx, query any) (any, error)` | Panics today, because the state machine is nil |
| `Metrics() map[string]any` | The stats as a flat map |
| `Reload(ctx) error` | Reloads config, see [hot reload](/docs/extensions/consensus/configuration#hot-reload) |
| `Health(ctx) error` | `storage not initialized` today |

## Service

`*consensus.Service` is the extension's `ConsensusService`. `NewConsensusService(config Config, logger forge.Logger, metrics forge.Metrics) (*Service, error)` builds one on its own, with the same stubbed components.

| Method | What it does today |
|---|---|
| `Start(ctx) error` | Logs each component it would initialise, starts the health, metrics and snapshot loops. A second call returns `ErrAlreadyStarted` |
| `Stop(ctx) error` | Stops the loops |
| `IsLeader() bool`, `GetLeader() string`, `GetRole() NodeRole`, `GetTerm() uint64` | `false`, `""`, `RoleFollower`, `0` |
| `Apply(ctx, cmd Command) error` | Not-leader error |
| `Read(ctx, query any) (any, error)` | Panics on the nil state machine |
| `Snapshot(ctx) error` | Panics on the nil state machine |
| `AddNode(ctx, nodeID, address string, port int) error`, `RemoveNode(ctx, nodeID string) error` | Not-leader error |
| `TransferLeadership(ctx, targetNodeID string) error`, `StepDown(ctx) error` | Not-leader error. Not implemented past that check |
| `GetStats() ConsensusStats`, `GetClusterInfo() ClusterInfo` | Stats and membership, mostly zero |
| `HealthCheck(ctx) error` | `storage not initialized` once started, `ErrNotStarted` before |
| `GetHealthStatus(ctx) HealthStatus` | Per-check details, unhealthy today |
| `UpdateConfig(ctx, config Config) error` | Validates, then copies the `observability`, `health` and `admin_api` sections |
| `GetRaftNode()`, `GetStateMachine()`, `GetClusterManager()`, `GetTransport()`, `GetDiscovery()`, `GetStorage()` | `nil` |

## LeadershipChecker

| Function or method | Description |
|---|---|
| `NewLeadershipChecker(service ConsensusService) *LeadershipChecker` | Wraps a service |
| `IsLeader() bool`, `GetLeader() string` | Pass through to the service |
| `RequireLeader() error` | A not-leader error naming the leader, or `nil` on the leader |
| `RequireQuorum() error` | `ErrNoQuorum`, or `nil` when the cluster has quorum |

## Errors

The sentinels and helpers are listed on the [features page](/docs/extensions/consensus/features#errors).

| Function | Description |
|---|---|
| `NewNotLeaderError(nodeID, leaderID string)` | Not-leader error carrying both IDs |
| `NewNoLeaderError()` | No-leader error |
| `NewTimeoutError(operation string)` | Timeout error |
| `NewNoQuorumError(required, available int)` | No-quorum error carrying the counts |
| `NewStaleTermError(current, received uint64)` | Stale-term error carrying both terms |
| `IsNotLeaderError`, `IsNoLeaderError`, `IsNoQuorumError`, `IsStaleTermError` | `errors.Is` checks |
| `IsRetryable(err)`, `IsFatal(err)` | Classify an error |
