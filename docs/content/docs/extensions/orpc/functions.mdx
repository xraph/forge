## Extension Entry Points

| Function | Description |
|---|---|
| `NewExtension(opts ...ConfigOption) forge.Extension` | Creates the extension from `DefaultConfig()` plus your options |
| `NewExtensionWithConfig(config Config) forge.Extension` | Same as `NewExtension(WithConfig(config))` |
| `DefaultConfig() Config` | The defaults listed on the [configuration](/docs/extensions/orpc/configuration) page |
| `(*Config) Validate() error` | Checks the endpoints, batch limit, request size, timeout and naming strategy |
| `(*Config) ShouldExpose(path string) bool` | Applies the include and exclude patterns to a path |

## Service

You get the service with `forge.Inject[*orpc.ORPCService](app.Container())`, or by the key `orpc`. It implements `ORPC` by passing every call to the server inside it.

| Function or method | Description |
|---|---|
| `NewORPCService(config Config, logger forge.Logger, metrics forge.Metrics) (*ORPCService, error)` | Validates the config and builds a server |
| `NewORPCServer(config Config, logger forge.Logger, metrics forge.Metrics) ORPC` | Builds a server on its own, without the extension |
| `(*ORPCService) Server() ORPC` | The server inside the service |
| `(*ORPCService) Name() string` | `"orpc-service"` |
| `Start`, `Stop`, `Health` | Lifecycle hooks called by the container |

## ORPC: Methods

| Method | Description |
|---|---|
| `RegisterMethod(method *Method) error` | Adds or replaces a method. `ErrInvalidMethodName` for an empty name |
| `GetMethod(name string) (*Method, error)` | `ErrMethodNotFoundError` when there's no such method |
| `ListMethods() []Method` | Every method, sorted by name |
| `GenerateMethodFromRoute(route forge.RouteInfo) (*Method, error)` | Builds a method that runs the route. Doesn't register it. Errors for a route marked with `forge.WithORPCExclude` |

## ORPC: Requests

| Method | Description |
|---|---|
| `HandleRequest(ctx context.Context, req *Request) *Response` | Runs one request through the interceptors and the method |
| `HandleBatch(ctx context.Context, requests []*Request) []*Response` | Runs a batch in order, after checking `enable_batch` and `batch_limit` |
| `Use(interceptor Interceptor)` | Adds an interceptor. They run in the order you add them |
| `SetRouter(router forge.Router)` | Sets the router that route-backed methods call. The extension does this in `Start` |

`Interceptor` is `func(ctx context.Context, req *Request, next MethodHandler) (any, error)`, and `MethodHandler` is `func(ctx any, params any) (any, error)`. The handler's `ctx` is a `context.Context`.

## ORPC: Schema and Stats

| Method | Description |
|---|---|
| `OpenRPCDocument() *OpenRPCDocument` | Builds the OpenRPC 1.3.2 document, methods sorted by name |
| `GetStats() ServerStats` | Request, error and batch counts and the average latency in seconds |

## Response Helpers

| Function | Description |
|---|---|
| `NewSuccessResponse(id any, result any) *Response` | A success response |
| `NewErrorResponse(id any, code int, message string) *Response` | An error response |
| `NewErrorResponseWithData(id any, code int, message string, data any) *Response` | An error response with `data` |
| `GetErrorMessage(code int) string` | The standard message for a JSON-RPC error code |
| `(*Request) IsNotification() bool` | True when the request has no `id`. The extension doesn't call it |

## Key Types

### `Method`

| Field | Type | Purpose |
|---|---|---|
| `Name` | `string` | Method name, for example `get.users.id` |
| `Description` | `string` | The route summary, for generated methods |
| `Params` | `*ParamsSchema` | Params schema for the OpenRPC document. Not used to validate |
| `Result` | `*ResultSchema` | Result schema for the OpenRPC document |
| `Handler` | `MethodHandler` | The function that runs the call |
| `RouteInfo` | `any` | The `forge.RouteInfo` behind a generated method |
| `Tags` | `[]string` | Tags, from `forge.WithTags` for generated methods |
| `Deprecated` | `bool` | Shown in the list and the document. Always false for generated methods |
| `Metadata` | `map[string]any` | The route's metadata, for generated methods |

### `ParamsSchema`, `ResultSchema` and `PropertySchema`

`ParamsSchema` has `Type`, `Properties map[string]*PropertySchema`, `Required []string` and `Description`. `ResultSchema` has the same fields without `Required`. `PropertySchema` has `Type`, `Description`, `Properties`, `Items *PropertySchema`, `Required` and `Example any`.

### `Request`

| Field | Type | JSON |
|---|---|---|
| `JSONRPC` | `string` | `jsonrpc`, must be `"2.0"` |
| `Method` | `string` | `method` |
| `Params` | `json.RawMessage` | `params` |
| `ID` | `any` | `id` |

### `Response` and `Error`

`Response` has `JSONRPC`, `Result any`, `Error *Error` and `ID any`. `Error` has `Code int`, `Message string` and `Data any`, and implements `error`.

### `ServerStats`

`TotalRequests`, `TotalErrors`, `TotalBatchReqs` (`int64`) and `AverageLatency` (`float64`, seconds). `TotalMethods` and `ActiveRequests` exist but are never updated.

### OpenRPC types

`OpenRPCDocument`, `OpenRPCInfo`, `OpenRPCContact`, `OpenRPCLicense`, `OpenRPCMethod`, `OpenRPCParam`, `OpenRPCResult`, `OpenRPCError`, `OpenRPCTag`, `OpenRPCComponents` and `OpenRPCServer` mirror the OpenRPC specification. The generated document fills `info`, `methods` and `servers`.

## Error Constants

| Constant | Value |
|---|---|
| `ErrParseError` | `-32700` |
| `ErrInvalidRequest` | `-32600` |
| `ErrMethodNotFound` | `-32601` |
| `ErrInvalidParams` | `-32602` |
| `ErrInternalError` | `-32603` |
| `ErrServerError` | `-32000` |

Sentinel errors: `ErrInvalidMethodName` and `ErrMethodNotFoundError` are returned as described above. `ErrMethodExists`, `ErrDisabled`, `ErrBatchDisabled`, `ErrBatchTooLarge` and `ErrRequestTooLarge` are declared but never returned.
