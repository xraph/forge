## How Config Is Loaded

The extension reads `extensions.mcp` from your config, and falls back to a top-level `mcp` key. Options you set in code win over the file, and the file wins over `DefaultConfig()`. So `base_path: /mcp` or `enabled: false` in YAML takes effect with a plain `mcp.NewExtension()`, and fields you leave out keep their defaults. One edge case: when the file has an `mcp` section, an option set to exactly its default value looks the same as no option at all, and the file wins for that field. A zero value that differs from the default, like `WithEnabled(false)`, still beats the file.

Forge reads `config.yaml` only when `EnableConfigAutoDiscovery` is on. `forge.DefaultAppConfig()` turns it on, but an `AppConfig` literal leaves it off. `WithRequireConfig(true)` makes a missing section an error at startup.

## YAML Keys

Keys are the snake_case form of each field name, listed in the table below. Older configs used the Go field names (`ToolPrefix`, `BasePath`), and those still apply. Each one logs a warning at startup naming the key to switch to, and if a section sets both spellings the snake_case one wins.

```yaml title="config.yaml"
extensions:
  mcp:
    enabled: true
    base_path: /_/mcp
    server_name: orders-api       # defaults to the app name
    server_version: 1.0.0         # defaults to the app version

    auto_expose_routes: true
    tool_prefix: shop_
    exclude_patterns: ["/_/*", "/internal/*"]
    include_patterns: []
    max_tool_name_length: 64

    enable_resources: false
    enable_prompts: false

    # Validated, but not applied to the endpoints (see below)
    require_auth: false
    auth_header: Authorization
    auth_tokens: []
    rate_limit_per_minute: 0      # 0 means unlimited

    enable_metrics: true          # not read
    schema_cache: true
```

## Programmatic Configuration

```go
ext := mcp.NewExtension(
	mcp.WithBasePath("/_/mcp"),
	mcp.WithAutoExposeRoutes(true),
	mcp.WithToolPrefix("shop_"),
	mcp.WithExcludePatterns([]string{"/_/*", "/internal/*"}),
	mcp.WithResources(true),
	mcp.WithPrompts(true),
)
```

## Config Struct Reference

| Field | YAML key | Type | Default | What it does |
|---|---|---|---|---|
| `Enabled` | `enabled` | `bool` | `true` | When false, the extension registers nothing |
| `BasePath` | `base_path` | `string` | `"/_/mcp"` | Prefix for every MCP endpoint. Can't be empty |
| `ServerName` | `server_name` | `string` | `""` | Name in `/info`. Empty means the app's name |
| `ServerVersion` | `server_version` | `string` | `""` | Version in `/info`. Empty means the app's version |
| `AutoExposeRoutes` | `auto_expose_routes` | `bool` | `true` | Turns routes into tools at start |
| `ToolPrefix` | `tool_prefix` | `string` | `""` | Prefix for generated tool names |
| `ExcludePatterns` | `exclude_patterns` | `[]string` | none | Exact paths or `/prefix/*` globs to leave out. Checked first |
| `IncludePatterns` | `include_patterns` | `[]string` | none | When set, only matching paths become tools |
| `MaxToolNameLength` | `max_tool_name_length` | `int` | `64` | Longer names are rejected. Must be at least 1 |
| `EnableResources` | `enable_resources` | `bool` | `false` | Mounts `/resources` and `/resources/read` |
| `EnablePrompts` | `enable_prompts` | `bool` | `false` | Mounts `/prompts` and `/prompts/:name` |
| `RequireAuth` | `require_auth` | `bool` | `false` | Not applied. Read by `AuthMiddleware` if you wire it |
| `AuthHeader` | `auth_header` | `string` | `"Authorization"` | Header `AuthMiddleware` checks |
| `AuthTokens` | `auth_tokens` | `[]string` | none | Accepted tokens. Required when `RequireAuth` is true |
| `RateLimitPerMinute` | `rate_limit_per_minute` | `int` | `0` | Not applied. Read by `RateLimitMiddleware` if you wire it. Can't be negative |
| `EnableMetrics` | `enable_metrics` | `bool` | `true` | Not read. Metrics are recorded whenever the app has a metrics backend |
| `SchemaCache` | `schema_cache` | `bool` | `true` | Gates `CacheSchema` and `GetCachedSchema`, which the extension doesn't call itself |
| `RequireConfig` | (code only) | `bool` | `false` | Fail at startup when no config section is found |

## Option Helpers

| Function | Sets |
|---|---|
| `WithEnabled(enabled bool)` | `Enabled` |
| `WithBasePath(basePath string)` | `BasePath` |
| `WithServerInfo(name, version string)` | `ServerName`, `ServerVersion` |
| `WithAutoExposeRoutes(autoExpose bool)` | `AutoExposeRoutes` |
| `WithToolPrefix(prefix string)` | `ToolPrefix` |
| `WithExcludePatterns(patterns []string)` | `ExcludePatterns` |
| `WithIncludePatterns(patterns []string)` | `IncludePatterns` |
| `WithResources(enable bool)` | `EnableResources` |
| `WithPrompts(enable bool)` | `EnablePrompts` |
| `WithAuth(authHeader string, tokens []string)` | `RequireAuth = true`, `AuthHeader`, `AuthTokens` |
| `WithRateLimit(limit int)` | `RateLimitPerMinute` |
| `WithRequireConfig(require bool)` | `RequireConfig` |
| `WithConfig(config Config)` | Replaces the whole config |

`MaxToolNameLength`, `EnableMetrics` and `SchemaCache` have no option of their own. Set them in YAML or through `WithConfig`. `NewExtensionWithConfig(cfg)` is the same as `NewExtension(WithConfig(cfg))`.
