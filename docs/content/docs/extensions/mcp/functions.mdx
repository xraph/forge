## Extension Entry Points

| Function | Description |
|---|---|
| `NewExtension(opts ...ConfigOption) forge.Extension` | Creates the extension from `DefaultConfig()` plus your options |
| `NewExtensionWithConfig(config Config) forge.Extension` | Same as `NewExtension(WithConfig(config))` |
| `DefaultConfig() Config` | The defaults listed on the [configuration](/docs/extensions/mcp/configuration) page |
| `(Config) Validate() error` | Checks the base path, name length, auth tokens and rate limit |
| `(Config) ShouldExpose(path string) bool` | Applies `Enabled`, `AutoExposeRoutes` and the include and exclude patterns to a path |

## Service

You get the service with `forge.Inject[*mcp.MCPService](app.Container())`, or by the key `mcp`.

| Function or method | Description |
|---|---|
| `NewMCPService(config Config, logger forge.Logger, metrics forge.Metrics) (*MCPService, error)` | Validates the config and builds a `Server` |
| `(*MCPService) Server() *Server` | The server that holds tools, resources and prompts |
| `(*MCPService) Name() string` | `"mcp-service"` |
| `Start`, `Stop`, `Health` | Lifecycle hooks called by the container |

## Server: Tools

| Method | Description |
|---|---|
| `NewServer(config Config, logger forge.Logger, metrics forge.Metrics) *Server` | Builds a server on its own, without the extension |
| `RegisterTool(tool *Tool) error` | Adds or replaces a tool. Fails on an empty name or one longer than `MaxToolNameLength` |
| `GetTool(name string) (*Tool, error)` | Looks a tool up by name |
| `ListTools() []Tool` | Every tool, sorted by name |
| `GenerateToolFromRoute(route forge.RouteInfo) (*Tool, error)` | Builds a tool from a route and remembers the route behind it. Doesn't register the tool |
| `ExecuteTool(ctx context.Context, tool *Tool, arguments map[string]any) (string, error)` | Returns `Tool executed: <METHOD> <path>`. Doesn't call the route. Errors for a tool with no route |

## Server: Resources

| Method | Description |
|---|---|
| `RegisterResource(resource *Resource) error` | Adds or replaces a resource. Fails on an empty URI |
| `RegisterResourceReader(uri string, reader ResourceReader) error` | Sets the function that produces a resource's content |
| `GetResource(uri string) (*Resource, error)` | Looks a resource up by URI |
| `ListResources() []Resource` | Every resource, sorted by URI |
| `ReadResource(ctx context.Context, resource *Resource) (Content, error)` | Runs the reader, or returns a text summary when there isn't one |

`ResourceReader` is `func(ctx context.Context, resource *Resource) (Content, error)`.

## Server: Prompts

| Method | Description |
|---|---|
| `RegisterPrompt(prompt *Prompt) error` | Adds or replaces a prompt. Fails on an empty name |
| `RegisterPromptGenerator(name string, generator PromptGenerator) error` | Sets the function that renders a prompt |
| `GetPrompt(name string) (*Prompt, error)` | Looks a prompt up by name |
| `ListPrompts() []Prompt` | Every prompt, sorted by name |
| `GeneratePrompt(ctx context.Context, prompt *Prompt, args map[string]any) ([]PromptMessage, error)` | Runs the generator, or returns one default user message |

`PromptGenerator` is `func(ctx context.Context, prompt *Prompt, args map[string]any) ([]PromptMessage, error)`.

## Server: Other

| Method | Description |
|---|---|
| `GetServerInfo() ServerInfo` | Name, version and capabilities |
| `CacheSchema(key string, schema *JSONSchema)` | Stores a schema when `SchemaCache` is on |
| `GetCachedSchema(key string) (*JSONSchema, bool)` | Fetches one |
| `Clear()` | Empties tools, resources, prompts and the schema cache |
| `Stats() map[string]any` | `tools`, `resources`, `prompts` and `enabled` |

## Middleware

Neither of these is applied by the extension. See [Authentication and Rate Limiting](/docs/extensions/mcp/features#authentication-and-rate-limiting).

| Function | Description |
|---|---|
| `AuthMiddleware(config Config, logger forge.Logger) forge.PureMiddleware` | Checks `AuthHeader` against `AuthTokens` when `RequireAuth` is on |
| `RateLimitMiddleware(config Config, logger forge.Logger, metrics forge.Metrics) forge.PureMiddleware` | Per-client limit of `RateLimitPerMinute`. A no-op when the limit is 0 |
| `NewRateLimiter(config Config, logger forge.Logger) *RateLimiter` | The limiter behind `RateLimitMiddleware`, with `Allow(clientID string) bool` and `Stop()` |

## Key Types

### `Tool`

| Field | Type | JSON |
|---|---|---|
| `Name` | `string` | `name` |
| `Description` | `string` | `description` |
| `InputSchema` | `*JSONSchema` | `inputSchema` |

### `JSONSchema`

`Type`, `Properties map[string]*JSONSchema`, `Items *JSONSchema`, `Required []string`, `Description`, `Enum []any`, `Format`, `Pattern`, `MinLength`, `MaxLength` (`*int`), `Minimum`, `Maximum` (`*float64`) and `AdditionalProperties any`.

### `Resource`

| Field | Type | JSON |
|---|---|---|
| `URI` | `string` | `uri` |
| `Name` | `string` | `name` |
| `Description` | `string` | `description` |
| `MimeType` | `string` | `mimeType` |
| `Schema` | `*JSONSchema` | `schema` |

### `Prompt` and `PromptArgument`

`Prompt` has `Name`, `Description` and `Arguments []PromptArgument`. `PromptArgument` has `Name`, `Description` and `Required bool`.

### `PromptMessage`

| Field | Type | JSON |
|---|---|---|
| `Role` | `string` | `role`, `"user"` or `"assistant"` |
| `Content` | `[]Content` | `content` |

### `Content`

`Type` (`"text"`, `"image"` or `"resource"`), `Text`, `Data` and `MimeType`.

### Request and response types

`CallToolRequest`, `CallToolResponse`, `ListToolsResponse`, `ReadResourceRequest`, `ReadResourceResponse`, `ListResourcesResponse`, `GetPromptRequest`, `GetPromptResponse` and `ListPromptsResponse` are the JSON bodies of the HTTP endpoints. `ServerInfo` holds `Name`, `Version` and `Capabilities`.
