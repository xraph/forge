## Overview

`github.com/xraph/forge/extensions/mcp` turns the HTTP routes you register into MCP-style tools. Each tool gets a name built from the route's method and path, a description from its `forge.WithSummary` text and a JSON Schema for its path parameters, query and body. You can also publish MCP resources and prompts backed by your own Go functions.

The extension registers an `*mcp.MCPService` in the container and mounts plain JSON endpoints under a base path (`/_/mcp` by default).

<Callout type="warn">
Read this before you connect an AI agent. Calling a route-backed tool does **not** run your handler: it returns the text `Tool executed: GET /orders/42`. The endpoints are plain JSON over HTTP, with no JSON-RPC 2.0 framing, no `initialize` handshake and no stdio or Streamable HTTP transport, so an MCP client such as Claude Desktop can't connect to them directly. `WithAuth` and `WithRateLimit` are validated but never applied to the endpoints. The [Features](/docs/extensions/mcp/features#calling-tools) page has the details.
</Callout>

## Quick Start

```go
package main

import (
	"log"
	"net/http"

	"github.com/xraph/forge"
	"github.com/xraph/forge/extensions/mcp"
)

func main() {
	app := forge.NewApp(forge.AppConfig{
		Name:        "orders-api",
		Version:     "1.0.0",
		HTTPAddress: ":8080",
		Extensions: []forge.Extension{
			mcp.NewExtension(
				mcp.WithExcludePatterns([]string{"/_/*"}),
			),
		},
	})

	r := app.Router()

	err := r.GET("/orders/:id", func(ctx forge.Context) error {
		return ctx.JSON(http.StatusOK, map[string]string{"id": ctx.Param("id")})
	}, forge.WithSummary("Fetch one order by ID"))
	if err != nil {
		log.Fatal(err)
	}

	err = r.POST("/orders", func(ctx forge.Context) error {
		return ctx.JSON(http.StatusCreated, map[string]string{"status": "created"})
	}, forge.WithSummary("Create an order"))
	if err != nil {
		log.Fatal(err)
	}

	if err := app.Run(); err != nil {
		log.Fatal(err)
	}
}
```

Then list the tools:

```bash
curl http://localhost:8080/_/mcp/info
curl http://localhost:8080/_/mcp/tools
```

`/_/mcp/tools` returns the two routes as tools, sorted by name:

```json
{"tools":[
  {"name":"create_orders","description":"Create an order","inputSchema":{"type":"object","properties":{"body":{"type":"object","description":"Request body"},"query":{"type":"object","description":"Query parameters (optional)","additionalProperties":true}}}},
  {"name":"get_orders_id","description":"Fetch one order by ID","inputSchema":{"type":"object","properties":{"id":{"type":"string","description":"Path parameter: id"},"query":{"type":"object","description":"Query parameters (optional)","additionalProperties":true}},"required":["id"]}}
]}
```

The exclude pattern keeps Forge's own `/_/health`, `/_/metrics` and similar routes out of the list. Routes under the MCP base path are always skipped. The extension reads the router when it starts, so register your routes before `app.Run()`.

## What It Registers

| Service | DI key | Type |
|---|---|---|
| MCP service | `mcp` | `*mcp.MCPService` |

Routes added to the Forge router in `Start()`, with the default base path:

| Method and path | What it does |
|---|---|
| `GET /_/mcp/info` | Server name, version and capabilities |
| `GET /_/mcp/tools` | `{"tools": [...]}` |
| `POST /_/mcp/tools/:name` | Calls a tool. Body: `{"name": "...", "arguments": {...}}` |
| `GET /_/mcp/resources` | Lists resources, when `EnableResources` is on |
| `POST /_/mcp/resources/read` | Reads one. Body: `{"uri": "..."}` |
| `GET /_/mcp/prompts` | Lists prompts, when `EnablePrompts` is on |
| `POST /_/mcp/prompts/:name` | Renders one. Body: `{"arguments": {...}}` |

## Resources and Prompts

Turn them on, then register them from a start hook once the service exists:

```go
app := forge.NewApp(forge.AppConfig{
	Name: "orders-api",
	Extensions: []forge.Extension{
		mcp.NewExtension(mcp.WithResources(true), mcp.WithPrompts(true)),
	},
})

err := forge.OnStarted(app, "mcp-content", func(ctx context.Context, a forge.App) error {
	svc, err := forge.Inject[*mcp.MCPService](a.Container())
	if err != nil {
		return err
	}

	srv := svc.Server()

	if err := srv.RegisterResource(&mcp.Resource{
		URI:      "orders://schema",
		Name:     "Order schema",
		MimeType: "application/json",
	}); err != nil {
		return err
	}

	if err := srv.RegisterResourceReader("orders://schema",
		func(ctx context.Context, r *mcp.Resource) (mcp.Content, error) {
			return mcp.Content{Type: "text", MimeType: r.MimeType, Text: `{"id":"string","total":"number"}`}, nil
		}); err != nil {
		return err
	}

	if err := srv.RegisterPrompt(&mcp.Prompt{
		Name:        "summarize_order",
		Description: "Summarize an order for a support agent",
		Arguments:   []mcp.PromptArgument{{Name: "id", Required: true}},
	}); err != nil {
		return err
	}

	return srv.RegisterPromptGenerator("summarize_order",
		func(ctx context.Context, p *mcp.Prompt, args map[string]any) ([]mcp.PromptMessage, error) {
			return []mcp.PromptMessage{{
				Role:    "user",
				Content: []mcp.Content{{Type: "text", Text: fmt.Sprintf("Summarize order %v in two lines.", args["id"])}},
			}}, nil
		})
})
```

`POST /_/mcp/resources/read` with `{"uri":"orders://schema"}` runs your reader, and `POST /_/mcp/prompts/summarize_order` with `{"arguments":{"id":"42"}}` runs your generator.

## Key Concepts

- Every route becomes a tool when `AutoExposeRoutes` is on (the default). The name is the verb mapped to a word (`GET` to `get`, `POST` to `create`, `PUT` to `update`, `PATCH` to `patch`, `DELETE` to `delete`), then the path with slashes turned into underscores and the `:` or `{}` around parameters dropped. `DELETE /users/:id` becomes `delete_users_id`.
- `ToolPrefix` goes in front of every generated name. A name longer than `MaxToolNameLength` (64) is skipped with a warning in the log.
- Resources and prompts are never generated. You register them, and their endpoints exist only when you turn them on.
- `ServerName` and `ServerVersion` default to the app's name and version.
